- **Основные посты (story/клифф):** 800-900 слов

- Никаких длинных тире (—) в текстах - только дефис (-).
- Мета-данные: // ИД-ПОСТА:, // ТЕМА:, // ДАТА:, // СТАТУС:
- Заголовок поста: НАЗВАНИЕ ПРОЕКТА + СЕЗОН + ГЛАВА N, ч.N: НАЗВАНИЕ НА РУССКОМ
