# 🎛 NOVELLS - POLL & ENGAGEMENT PLAYBOOK (разнообразие интерактива)

Заведено 17.06.2026. Чтобы ротировать формы вовлечения ОСОЗНАННО, а не по привычке («как Виктория делает X?» × 3 опции каждый день). Наша модель неизменна: КОЛЛЕКТИВНЫЙ голос → ЕДИНЫЙ таймлайн, один канал, ручное ведение, без ботов/ветвления (OS §11.7 «НЕ берём»). Всё ниже - поверх неё.

## 🗳 A. ТИПЫ ОПРОСОВ (ротировать; не один тип 2 Главы подряд)

| Тип | Вопрос про | Когда |
|-----|-----------|-------|
| **Действие** (база) | «как ГГ делает X» | дефолт - но не каждый раз |
| **Ставка/цена** | «чем ГГ ПЛАТИТ за ход» (выбор риска, не действия) | когда цена интереснее действия |
| **Приоритет/ресурс** | «на что тратит ограниченное» (время/деньги/доверие) | дефицит-моменты |
| **К кому** | фокус романтической линии | двигать affinity, любовные узлы |
| **Ценностный** | «что важнее: X или Y» - ось характера ГГ | определять/проявлять ГГ (трейты) |
| **Темп** | «тихо vs ва-банк» | привязка к счётчику-гончей (HEAT и пр.) |
| **Дилемма** | оба варианта плохи | запустить «третий путь» (OS §3) |
| **Предсказание/теория** | «кто, по-твоему, предал?» - НЕ меняет сюжет | мистерии; оплатить позже; вовлечение без развилки |

## 🔢 B. КОЛИЧЕСТВО ОТВЕТОВ (варьировать)
- **2** - острая развилка, высокая ставка (бинар).
- **3** - стандарт: два полюса + третий путь/середина.
- **4** - РЕДКО, когда реально 4 разных (4 двери/4 LI); риск распыления голосов - не злоупотреблять.
- **Мульти-селект** - собрать команду / что сохранить / ранжировать (Telegram allows multiple answers). Хорош для «возьми 2 из 4».
- Опции всегда **значимо разные** (не «X / X+1»).

## 📊 C. ЯРУСЫ ГЛУБИНЫ ВЛИЯНИЯ (помечать вес - читатель чувствует ставку; масштаб дельт по STATS_RULES)
| Ярус | Что меняет | Дельты | Частота |
|------|-----------|--------|---------|
| **МИКРО** (реакц/мелкий) | окрашивает беат | 0 / нудж | ежедневно |
| **ТАКТИЧЕСКИЙ** (дневной опрос) | лепит следующую сцену | стандарт ±3-5 | 2/день |
| **МЕЙДЖОР** (конец блока) | разворачивает арку/блок | усиленные / разблокировки порогов | конец блока |
| **СЕЗОН-ОПРЕДЕЛЯЮЩИЙ** (редко) | ветка финала (матрица ENDINGS) | выбор исхода, не только числа | финал/ключевые твисты |
- Мейджор/сезонные - анонсировать как «большой выбор» (вес виден). Не делать каждый день - обесценится.

## 🧩 D. ПОМИМО ОПРОСОВ И РЕАКЦИЙ (механики коллективного голоса)

- **🆕 QUIZ-ОПРОС (native Telegram quiz, правильный ответ):** для загадок/лор-чеков («кто на фото?», «чей почерк?»). Геймификация внимания. ⚠️ quiz показывает правильный ответ СРАЗУ после голоса - поэтому НЕ для 🔒-секретов (их вскрывать по леджеру TRACKERS); только для уже-раскрываемого лора ИЛИ как «проверь себя». Для мистерии без раскрытия - брать тип «Предсказание» (обычный опрос, ответ позже).
- **🆕 РЕАКЦ-ПОРОГ-РАЗБЛОКИ:** «наберём N 🔥 → теневой слот ночью / выложу DOSSIER / раньше следующий пост». Геймификация темпа + разгон охвата. Привязывать к реальному бонусу, не пустой.
- **🆕 КОММЕНТ-В-КАНОН:** топовая теория/реплика из комментов вплетается в беат; **In-character Q&A** - читатель «спрашивает героя», автор отвечает ОТ ЛИЦА (по речевой манере CHARACTER_DEPTH). Коммент буквально лепит сцену → привязанность.
- **🆕 ЧИТАТЕЛЬСКИЙ НЕЙМИНГ:** «придумайте кодовое имя операции / название коктейля/места» - лучшее становится каноном. Со-творчество, низкая ставка, высокая привязанность.
- **СПОЙЛЕР-СЛОЙ как «тайный выбор»:** второй мелкий опрос/находка под катом для самых вовлечённых (углубляет спойлер-механику §11.7.B).
- **КРУЖОЧКИ / голос от лица героя** (§11.7.E): 20-30-сек монолог перед пиковой сценой. Не голос-механика, но вовлечение. Точечно, на пики.

**Дисциплина новых механик:** не ломают коллективный-голос/единый-таймлайн; числа - по STATS_RULES; секреты - по леджеру TRACKERS; без кросс-проектных упоминаний.
