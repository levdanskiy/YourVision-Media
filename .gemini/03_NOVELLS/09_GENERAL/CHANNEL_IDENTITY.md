# 🌀 CORE - ИДЕНТИЧНОСТЬ КАНАЛА (источник истины; залочено 13.06.2026, решение пользователя)

Официальное название, дескриптор и описание канала. Все навигаторы, обложки, лого, анонсы - по этому файлу.

---

## 📛 НАЗВАНИЕ
**CORE** (рус. **ЯДРО**). Дескриптор-строка: **«CORE. Центральный узел Мультиверса.»**

## 📝 ОПИСАНИЕ КАНАЛА (bio)
> **CORE. Центральный узел Мультиверса.**
> Интерактивные архивы. Твои решения меняют исход.
> Некоторые миры открыты. Остальные - ждут.

## 🧭 КОНЦЕПЦИЯ (мета-рамка над всеми новеллами)
Канал = **ядро мультивселенной**; каждая новелла = **мир/архив**, который можно «открыть». Читатель не зритель, а оператор архива: его опросы/реакции меняют исход. Ротация сезонов = «некоторые миры открыты сейчас, остальные ждут своей очереди» (банк идей и будущие проекты - буквально «ждущие миры»).

**Как это сшивает нашу структуру:**
- **Идущий сезон** = «открытый мир» (сейчас - Orchid).
- **Ротация/банк** = «ждущие миры» (Eleyia, KM, Белая Дама, Судья Крови, Горизонт, Чернозём, Код, Антропос, лайты).
- **Спешлы** = «временные разломы» в ядре (праздничные/событийные/свободные).
- **Единый канал** = одно ядро, много миров (правило одного канала логично: ядро одно).

## 🗣 ТОН ОБЩЕКАНАЛЬНЫХ ТЕКСТОВ (навигаторы/анонсы/мета)
Сдержанно-загадочный, «архивно-мультиверсный»: миры «открываются»/«ждут»/«архив такого-то мира»; читатель - «оператор»/«твои решения». БЕЗ кросс-упоминаний СЮЖЕТОВ между мирами (мета-рамка можно, спойлеры миров - нет). Только дефис.
