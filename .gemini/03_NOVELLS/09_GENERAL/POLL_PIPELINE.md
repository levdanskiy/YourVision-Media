# 🔄 POLL PIPELINE - конвейер «опросы → Глава + дев-слоты»

Срабатывает АВТОМАТИЧЕСКИ, как только пользователь присылает результаты опросов/реакций активного проекта. Не ждать отдельной команды «пиши» - результаты опросов = триггер всего цикла. (Указание пользователя 18.06.2026.)

> Это процесс для главного потока (нарратив - моя работа, не агентов). Механические шаги можно отдавать субагентам/скриптам. Опросы ведут сюжет (`feedback_novells_polls_drive_stories`).

---

## ШАГИ (по порядку, каждый раз)

**0. ПАРСИНГ ВХОДА.** Разобрать присланное: какие вопросы, какой вариант победил (%/голоса), какие реакции-нуджи. Сопоставить с открытыми опросами из STATE (что именно закрывали).

**1. АУДИТ ПЕРЕД ПИСЬМОМ** (`feedback_novells_audit_before_writing`). Где мы в сезоне/блоке (ROADMAP), что опубликовано, кто давно не получал сцену/опрос, какой тип клиффа был прошлым (ротация). 30 секунд, чтобы Глава легла в структуру.

**2. ПРИМЕНИТЬ ДЕЛЬТЫ.** affinity/HEAT/счётчики по `STATS_RULES` → `STATS.json` (через stats-apply.py или правкой), запись в history с причиной и привязкой к опросу. Предсказания-опросы и сюжетные фигуры - без дельт. Проверить разблокировки порогов (DOSSIER/NOTEBOOK/…).

**3. НАПИСАТЬ СЛЕДУЮЩУЮ ГЛАВУ.** Главный поток, голос по `VOICE_LOCK`, канон по `CANON`. Глава ПОТРЕБЛЯЕТ исходы опросов (победивший вариант = что произошло; реакция = микро-беат). Сетка постов по `POSTING_SCHEDULE` (MAIN 10/13/16/18/20 + реакц-слот ~14:30 + доп при пик-Главе). Держать 🔒-локи канона.

**4. ЗАСЕЯТЬ СЛЕДУЮЩИЕ ОПРОСЫ.** Глава заканчивается новыми развилками (главный опрос + при необходимости предсказание/реакц) - они поведут следующую Главу. Без них цикл рвётся.

**5. QA-ГЕЙТ.** Прогнать `novells-qa` на написанной Главе (голос/канон/числа/имена-в-промптах/подвал/мусор). Поправить дрейф ДО коммита.

**6. ОБНОВИТЬ СОСТОЯНИЕ.** `STATE.md` (новая строка-шапка с исходами + что написано + что ждём), `POLL_LOG.json`, `TRACKERS.md` (cast-appearance/cadence/secret-ledger), `METRICS_LOG.md` (запись цикла). **Навигатор-перезакреп - ПО РИТМУ ~каждые 5 Глав** (v-инкремент: v1 старт, v2 Г5, v3 Г10, v4 Г15…) ИЛИ при крупном сдвиге (взят узел / новая ключевая фигура / смена блока). НЕ «по необходимости» - проверять кратность 5 каждый цикл, чтобы не проскочить.

**7. ДЕВ-СЛОТЫ - 2 КРУГА** (`project_novells_dev_backlog`, `feedback_novells_incubator_mining`). Каждый круг - пакет ярусов A (ротация)/B (текущий)/C (за углом)/D (банк-инкубатор, огранка по тон-ротации 🌑/☀️/⚖️, идея S1 → нумерованная папка)/E (спешлы). Можно параллелить `novells-incubator-polish`. Бэклог - в `09_GENERAL/DEV_BACKLOG.md`.

**8. КОММИТ.** pre-commit-novells (lint), commit на main, post-commit-guard двигает ветку `novells`. Co-Authored-By: Claude Opus 4.8.

**9. ОТЧЁТ.** Кратко: что произошло по опросам → что в Главе → какие опросы теперь ОТКРЫТЫ (для следующего ввода) → что сделано в дев-слотах. Без воды.

## ЧТО ЕЩЁ В КОНВЕЙЕРЕ (расширения)
- **Засев следующих опросов** (шаг 4) - критично: иначе следующий ввод нечем кормить.
- **QA-гейт** (шаг 5) - агент ловит дрейф до коммита, как поймал ранний раскрыв секрета в Г8.
- **Метрики** (шаг 6) - закрываем петлю обратной связи (что заходит).
- **Аудит ротации каста** - чтобы никто не выпадал (`feedback_novells_all_characters_appear`).
- **Тон-ротация в дев-слоте D** - тёмное/светлое/нейтральное поровну.
