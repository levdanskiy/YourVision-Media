# 🔄 POLL PIPELINE - полный конвейер «опросы → весь вечерний цикл»

Срабатывает АВТОМАТИЧЕСКИ, как только пользователь присылает результаты опросов/реакций ЛЮБОЙ активной новеллы. Не ждать команды «пиши» - результаты опросов = триггер всего цикла. (Указание пользователя 18.06.2026.)

> 🔑 **ГЛАВНОЕ ПРАВИЛО (18.06.2026):** в конвейере я делаю **АБСОЛЮТНО ВСЁ** - ни один пункт не «по необходимости», ни один не «на завтра». Каждый цикл прохожу ВЕСЬ чеклист и проверяю каждый пункт явно (даже если ответ «не сработало в этот раз - почему»). **ТАК В КАЖДОЙ НОВЕЛЛЕ** - Orchid, Kingmaker, Eleyia, Белая Дама, спешлы: процесс один, подставляется проектная система (свой VOICE_LOCK/CANON/STATS/счётчики/роадмап).
>
> Нарратив - моя работа (главный поток). Механику можно отдавать субагентам/скриптам. Опросы ведут сюжет (`feedback_novells_polls_drive_stories`).

## ✅ МАСТЕР-ЧЕКЛИСТ ЦИКЛА (проходить ВЕСЬ, каждый раз)

### A. ВХОД И ПОДГОТОВКА
- [ ] **A1. Парсинг входа.** Какие вопросы закрыты, что победило (%/голоса), какие реакции-нуджи. Сопоставить с открытыми опросами из `STATE`.
- [ ] **A2. Аудит перед письмом.** Где в сезоне/блоке (`ROADMAP`); что опубликовано; кто давно не получал сцену/опрос (`SUPPORTING_CAST`, «все герои появляются»); какой тип клиффа был прошлым (ротация); открытые 🔒-локи и что сейчас можно/нельзя раскрывать.

### B. ЧИСЛА И МЕХАНИКА
- [ ] **B1. Применить ВСЕ дельты.** affinity/HEAT и любые проектные счётчики (Orchid HEAT-Софи; Eleyia ВЕРНОСТЬ; KM СЧЁТ; и т.д.) по `STATS_RULES` → `STATS.json` + запись в history с причиной и привязкой к опросу. Предсказания-опросы и сюжетные фигуры - без дельт (зафиксировать «без дельт»).
- [ ] **B2. Пороги разблокировок.** Проверить кратность 25/50/75/100 (или проектные) по КАЖДОЙ линии: если порог пробит - запланировать разблок (DOSSIER/NOTEBOOK/STORY/SHADOW_HOOK) в этой или следующей Главе, отметить triggered в STATS.

### C. КОНТЕНТ ГЛАВЫ (главный поток)
- [ ] **C1. Написать Главу.** Голос по `VOICE_LOCK`, канон по `CANON`. Потребляет исходы опросов (победитель = что произошло; реакция = микро-беат). Держать 🔒-локи. Тональный баланс (не «только плохо»), романтика-двигатель, юмор-беат, речевые тики каста.
- [ ] **C2. Полная сетка постов** (`POSTING_SCHEDULE`): MAIN 10/13/16/18/20 + **реакц-слот ~14:30** (стандарт КАЖДЫЙ день) + доп-окна 11:30/21:30 по плану + **теневой доп-слот ~21:00 при пик-Главе** (клифф блока/твист/финал). Ничего из обязательного не пропускать. **РЕАКЦ-СЛОТ - строго ЗАЛОЧЕННЫМ набором эмодзи проекта** (Orchid 🎲♠️💋🧊 / Eleyia 🫧⚡🤝🌫 / см. `ENGAGEMENT_USAGE_LEDGER` §наборы); настроение дня кладётся на фикс-словарь, новые эмодзи НЕ выдумывать; подвал реакц-поста - эмодзи из набора.
- [ ] **C3. Засеять следующие опросы С РАЗНООБРАЗИЕМ + УЧЁТ ВИДОВ** (`POLL_ENGAGEMENT_PLAYBOOK` + `ENGAGEMENT_USAGE_LEDGER`). Глава кончается новыми развилками: главный опрос + предсказание/реакц-микроголос. **Сверить `ENGAGEMENT_USAGE_LEDGER`: что ⬜ не использовано / 🔸 частично - и по возможности развернуть НЕиспользованный вид**, а не крутить любимые. Варьировать тип (выбор/ставка/приоритет/к-кому/ценностный/темп/дилемма/предсказание), число ответов (2-4/мульти), ярус (микро/тактический/мейджор/сезон), + механики D (quiz/реакц-порог/нейминг/Q&A-в-канон/кружочек/спойлер-выбор). НЕ один формат две Главы подряд. **После выбора - обновить статусы в ENGAGEMENT_USAGE_LEDGER.** Без засева цикл рвётся - ОБЯЗАТЕЛЬНО.
- [ ] **C4. Визуал в КАЖДОМ посте.** Промпт по проектному `VISUAL_PROFILES`/`PROMPT_BASE`: имена+видовые/портретные черты в кадре, без Midjourney-флагов (Reve, aspect текстом), фотореализм/лин проекта. Безликая предметка - только когда героя в кадре нет.
- [ ] **C5. Лор-слой.** Лор-карта/DOSSIER/глоссарий-карточка/спойлер-слой по очереди проекта (если по ритму положено - сделать; если нет - отметить «не сегодня»).
- [ ] **C6. 🎵 Саундтрек Главы** (дифференциатор §11.7.F). Строка `🎵 *Исполнитель - Трек*` в завязке (10:00) + в `// ТЕМА`. **РАЗНООБРАЗИЕ ОБЯЗАТЕЛЬНО:** тянуть из проектной палитры `SOUNDTRACK_S*.md` (один мир-настроение, РАЗНЫЕ артисты), матчить тон Главы. **НЕ повторять артиста подряд / не чаще ~1 в 4-5 Глав** (урок 20.06: скатился в Massive Attack ×5 - так НЕЛЬЗЯ). Обновлять лог в SOUNDTRACK после выбора. Нет файла палитры у проекта - завести.

## 🧭 ПРИНЦИПЫ
- **Абсолютно всё** - чеклист проходится целиком; пропуск = ошибка (как пропущенный навигатор v3 18.06). Если пункт реально неприменим в этот цикл - явно отметить почему, не молча скипать.
- **Один процесс - все новеллы.** Подставляется проектная система. Активный проект - из `STATE`/брифа сессии.
- **Опросы ведут сюжет.** STORY - следствие прошедших опросов; засев следующих обязателен.
- **Локи канона** держим; предсказания-опросы не сворачивают сюжет и не дают дельт.
