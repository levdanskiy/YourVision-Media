## 📅 МОДЕЛЬ ДЕВ-СЛОТОВ: «ФОКУС + ОБСЛУЖИВАНИЕ» (переформат 15.06.2026, глубина > ширина)

Прежний ритуал «по слоту в каждый ярус A-E за сессию» заменён: он гнал вширь, а правило - **глубина > ширина**. Новая модель - один глубокий ФОКУС + лёгкое обслуживание + ритм огранки.

> ⚠️ **КОРРЕКЦИЯ 21.06.2026 (указание пользователя):** дев-слот = **ПРОХОД ПО ВСЕМ НОВЕЛЛАМ + проработка инкубатора** (как круги A-E ранее), НЕ «один фокус». Прежний разворот «глубина>ширина / один фокус» отменён - он сужал, проекты простаивали. Возвращаем ШИРИНУ: каждый дев-заход касается каждого активного/готовящегося проекта + двигает инкубатор. Календарь ниже задаёт, кому в этом проходе достаётся БОЛЬШЕ глубины, но не вместо остальных.

**Сессия дев-слотов = ПРОХОД ПО ВСЕМ (восстановлен 21.06):** в каждый заход - касание/продвижение по КАЖДОМУ активному и готовящемуся проекту + инкубатор:
- **Eleyia** (ведущий запуск) · **Kingmaker S2** · **Белая Дама** · **Снегурочка** (спешл) · **Белград-2027** (спешл) · **Orchid** (лор/обслуживание текущего сезона).
- **🪛 ИНКУБАТОР:** огранка ≥1 идеи S0→S1 по **ТОН-РОТАЦИИ** (🌑→☀️→⚖️) + добавление новых идей по запросу пользователя. Пачкой через `novells-incubator-polish` (параллельно, ФОРГРАУНД).
- **ГЛУБИНА по календарю:** проект ближе к старту получает в проходе больший кусок (Eleyia сейчас), остальные - поддерживающее касание (не простаивают). Лучше все живые + один глубже, чем один глубокий и пять забытых.
