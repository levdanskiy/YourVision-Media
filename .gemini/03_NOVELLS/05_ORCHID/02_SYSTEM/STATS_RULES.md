# 💎 ORCHID - STATS RULES (числа со смыслом; залочено 11.06.2026)

Affinity и HEAT двигаются ПО ПРАВИЛАМ, не на глаз. Каждое движение - в `stats_deltas` записи опроса (POLL_LOG) и в STATE. Читателю числа не показываем (узнаёт через разблокировки/сцены), но HEAT можно подсвечивать образами («в блокноте Софи уже три страницы»).

---

## 💠 AFFINITY (по линии, 0-100)

| Событие | Дельта |
|---|---|
| Линия открыта (первая сцена-контакт) | +5 |
| Заряжённая сцена/беат 18:00 с героем | +3 |
| Выбор опроса В ПОЛЬЗУ героя (фокус/доверие/близость) | +5 |
| Выбор опроса ПРОТИВ героя (холод/использование/поводок) | -3 |
| Интимная сцена | +8 |
| Виктория раскрывает герою часть ПРАВДЫ (не легенды) | +7 |
| Герой прикрыл её делом (риск ради неё) | +5 |
| Предательство/удар (с любой стороны) | -10 |

Пороги разблокировок: 25 DOSSIER / 50 NOTEBOOK PAGE / 75 STORY / 100 SHADOW HOOK - концепты в `AFFINITY_UNLOCKS.md`. **Николя капится на 99 до финала** (100 = мистерия).

**Ретро-сверка (Г1-Г2, сходится):** Максимилиан = открытие 5 + беат 18:00 Г2 3 = **8** ✓. Николя = открытие 5 + клифф-контакт Г1 (знает правду = вынужденная искренность) 5 = **10** ✓.

## 🔥 HEAT - СЧЁТЧИК СОФИ (0-10, видимая цена шума)

| Событие | Дельта |
|---|---|
| Громкий публичный ход (сорвать банк, скандал, слава) | +2 |
| Прямой контакт с Софи / попадание в её блокнот | +1 |
| Взлом узла Orchid Window (любой) | +1 |
| Грязный след (свидетель, камера, документ с дырой) | +1 |
| Тихая Глава (ни одного публичного хода) | -1 |
| Активная зачистка следа (потратить сцену/выбор) | -2 |

**Пороги (что делает Софи):**
- **3 - НАБЛЮДЕНИЕ:** Софи рядом, пассивно фиксирует (статус сейчас).
- **5 - ПРОВЕРКА:** запросы по легенде; «наследницу» начинают проверять документально - легенда под нагрузкой.
- **7 - ОПЕРАЦИЯ:** Европол разворачивает активную разработку: наружка, прослушка, подставной игрок за её столом.
- **10 - КРИЗИС:** ордер/задержание - кризисный беат (не обязан кончаться арестом, но ломает план).

**Текущий HEAT = 3** (Г1 слава +2, Г2 контакт с Софи +1) -> порог НАБЛЮДЕНИЕ достигнут (клифф Г2 «я теперь часто буду рядом» = его драматизация).

## 📐 ДИСЦИПЛИНА

- Каждая закрытая Глава: пересчитать affinity+HEAT по таблицам, записать в STATE и в `stats_deltas` POLL_LOG.
- Дельты вне таблиц - можно в исключительных сюжетных случаях, с пометкой «вне правил: почему».
- HEAT-пороги - это ОБЯЗАТЕЛЬСТВА сюжета: достигли 5 - проверка легенды происходит, не откладывается.
