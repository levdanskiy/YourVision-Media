## 🗳 ФОРМАТ ГОЛОСОВАНИЙ KM

**НЕ использовать эмодзи в опросах!** Использовать текстовый формат:

### Формат:
```
POLL #1: (вариант 1 / вариант 2 / вариант 3)
POLL #2: (вариант 1 / вариант 2 / вариант 3)
```

### Примеры из S1:
- POLL #1: «Раскрыть родство» (100%)
- POLL #2: (поддержать / отклонить как преждевременное / раскрыть родство публично)
- PHASE FINAL VOTE: (принять корону = трон+поводок / отказаться = сорвать капкан / перевернуть капкан)

### Правило:
- **НЕТ эмодзи** в вариантах голосования
- **ТЕКСТОВЫЙ формат** (как в S1)
- **🖤** используется ТОЛЬКО в заголовках и подписях канала
