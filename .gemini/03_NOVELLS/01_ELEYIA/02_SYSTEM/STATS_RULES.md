# 🪔 ELEYIA - STATS RULES (числа со смыслом; залочено 11.06.2026, дев-слот #2)

Affinity (синхронизация) и «ВЕРНОСТЬ» двигаются ПО ПРАВИЛАМ, не на глаз. Каждое движение - в `stats_deltas` записи опроса (POLL_LOG S2) и в STATE. Читателю числа не показываем (узнаёт через разблокировки - пороги 25/50/75/100 в `MECHANICS.md` §2 действуют с S1); ВЕРНОСТЬ можно подсвечивать образами («браслет сегодня калибровали дважды»).

---

## 💠 AFFINITY / СИНХРОНИЗАЦИЯ (по линии, 0-100)

Работает и для LI, и для не-LI (семья/друзья - как Марта 30 в S1): «синхронизация» - универсальная механика мира.

| Событие | Дельта |
|---|---|
| Линия открыта (первая сцена-контакт сезона для нового героя) | +5 |
| Заряжённый беат 18:00 с героем | +3 |
| Выбор опроса В ПОЛЬЗУ героя (фокус/доверие/близость) | +5 |
| Выбор опроса ПРОТИВ героя (холод/дистанция/использование) | -3 |
| Поцелуй / признание (пик школьной эпохи - интим-кап!) | +8 |
| Ян раскрывает герою правду о себе/даре (не маску) | +7 |
| Герой прикрыл Яна делом (риск ради него - перед Директоратом, браслетом, отцом) | +5 |
| Предательство/удар (с любой стороны) | -10 |

Пороги разблокировок (с S1, `MECHANICS.md`): 25 Первая искра / 50 Резонанс (flashback) / 75 Глубокий Синк / 100 Единый Пульс. Пер-герой концепты порогов - `AFFINITY_UNLOCKS.md` Eleyia (бэклог, до старта S2). **Ведущая линия капится на 99 до сезонной кульминации** (100 = Единый Пульс - только романтическая кульминация финала, по ведущей affinity).

| Герой | % | Примечание |
|---|---|---|
| Микас | 88 | Якорь; 75 пройден в S1 - на грани Единого Пульса, кап 99 |

| Марта | 30 | Сестра (не LI): 25 открыт в S1 |

## 📿 «ВЕРНОСТЬ» - СЧЁТЧИК ДИРЕКТОРАТА (0-10, цена непокорности)

Нейро-браслет «Верность» фиксирует ментальную активность; счётчик = насколько Ян «на карандаше» у Директората Лицея (аналог HEAT Софи в Orchid - но здесь следит СИСТЕМА, не человек).

| Событие | Дельта |
|---|---|
| Публичный резонанс / ментальный всплеск при свидетелях | +2 |
| Браслет вспыхнул красным (зафиксированный контакт) | +1 |
| Нарушение комендантского часа / запретная зона (Подвалы) | +1 |
| Донос/рапорт на Яна (одноклассник, Элара, куратор) | +1 |
| Тихая образцовая Глава (ни одного зафиксированного нарушения) | -1 |
| Показательная лояльность (потратить сцену/выбор на «примерного ученика») | -2 |

**Пороги (что делает Директорат) - ОБЯЗАТЕЛЬСТВА сюжета:**
- **3 - ПРИСМОТР:** браслет калибруют чаще, первое предупреждение семье (ориентир: конец блока I).
- **5 - КУРАТОР:** Яну назначают личного куратора-надзирателя (обязательство блока II, роадмап).
- **7 - ИЗОЛЯЦИЯ:** ограничение контактов (Микас/зоны/переписка с Кёнигсбергом) - давление на все линии разом.
- **10 - ИЗЪЯТИЕ:** Яна забирают на «Очищение Камня» - кризисный беат финала (не обязан кончаться ритуалом, но ломает план).

**Старт S2: ВЕРНОСТЬ = 1** (хвост репутации S1: Ян уже «в списке», но без активного дела). Ориентиры роадмапа: конец блока I = 2-3, блок II = 4-6 (куратор), финал = 8-10.

## 🧪 ЯНТАРНАЯ ЖАЖДА (легаси-механика S1)

В S2 школьной эпохи ЧИСЛОМ не ведём: Жажда - нарративный фон (голод дара, не счётчик), полноценная механика вернётся с Sync-3 в универ-эпоху (S4+). Решение 11.06.2026 - чтобы не плодить счётчики поверх ВЕРНОСТИ.

## 📐 ДИСЦИПЛИНА

- Каждая закрытая Глава: пересчитать affinity+ВЕРНОСТЬ по таблицам, записать в STATE и в `stats_deltas` POLL_LOG.
- Дельты вне таблиц - можно в исключительных сюжетных случаях, с пометкой «вне правил: почему».
- Пороги ВЕРНОСТИ - обязательства: достигли 5 - куратор появляется, не откладывается.
