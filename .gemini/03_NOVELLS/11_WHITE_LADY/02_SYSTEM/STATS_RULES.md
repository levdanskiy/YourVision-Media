# 👻 БЕЛАЯ ДАМА - STATS RULES + AFFINITY UNLOCKS (числа со смыслом; залочено 11.06.2026, дев-слот)

Числа двигаются по правилам, не на глаз; каждое движение - в `stats_deltas` POLL_LOG и в STATE (стандарт NOVELLS_OS §11.5). Читателю числа не показываем. Старт S1 ~17.10 (ротация).

## 💞 ДВЕ ЛИНИИ - ДВЕ ПРИРОДЫ ЧИСЕЛ

### ЛИГА (живая) - AFFINITY 0-100, классическая

| Событие | Дельта |
|---|---|
| Линия открыта (первая сцена-контакт) | +5 |
| Тёплый беат 18:00 (работа рядом, Лиго, песни) | +3 |
| Выбор опроса в её пользу | +5 |
| Выбор против (холод/выбор Эльзы в ущерб ей) | -3 |
| Поцелуй / интимная сцена (живая линия, 19+ мир взрослый) | +8 |
| Александр делится правдой об озере/Эльзе (не прячет) | +7 |
| Она прикрыла его перед общиной/отцом | +5 |
| Предательство/обман | -10 |

### ЭЛЬЗА / БЕЛАЯ ДАМА (призрак) - «СВЯЗЬ» 0-100, невозможная близость

Растёт не касанием - ПАМЯТЬЮ: чем больше правды о ней вспомнено/возвращено, тем она ближе и тем она... живее? (вопрос сезона).

| Событие | Дельта |
|---|---|
| Первая встреча (видение признано, не «показалось») | +5 |
| Ночная сцена-контакт (берег/зеркало/коридор) | +3 |
| Выбор опроса к ней (идти за ней, слушать, не бежать) | +5 |
| Возвращена часть её правды (имя/вещь/запись из XIX в.) | +7 |
| Обряд/дайна, спетая ДЛЯ неё | +5 |
| Попытка «изгнать»/отвергнуть её | -10 |

**Кап Эльзы = 99 до финала** (100 = развязка её тайны: упокоение/иное - решают опросы). Высокие пороги открывают флешбэки XIX века ЕЁ глазами.

### Разблокировки (обе линии, стандарт 25/50/75/100)
25 DOSSIER (привычка/деталь) · 50 NOTEBOOK (флешбэк-прошлое; у Эльзы - страница 18XX) · 75 STORY (сокровенное; у Эльзы - ночь её гибели ЧАСТИЧНО) · 100 SHADOW HOOK (главный секрет линии; только кульминация).

## 🌊 «ЗОВ ОЗЕРА» - СЧЁТЧИК 0-10 (цена близости к тайне)

Аналог HEAT/ВЕРНОСТИ: насколько озеро забрало Александра. Двигают выборы в сторону Эльзы/тайны; снижают - дневная жизнь (восстановление, Лига, община).

| Событие | Дельта |
|---|---|
| Ночная сцена с Эльзой / у воды | +1 |
| Возвращение её правды (каждый крупный кусок) | +1 |
| Обряд на грани (зеркала, полночь, вода) | +2 |
| Полный день живой жизни (стройка/община/Лига, без озера) | -1 |
| Тёплый якорь-выбор (остаться у камина, отказаться от зова) | -2 |

**Пороги - обязательства сюжета:**
- **3 - СНЫ:** озеро приходит ночами; вода в снах поднимается.
- **5 - ЛУНАТИЗМ:** Александр просыпается на берегу; Ансис находит следы (первым замечает ОН).
- **7 - ГРАНЬ:** зов наяву - вода зовёт войти; Лига видит, КЕМ он становится (кризис живой линии).
- **10 - ОЗЕРО ТРЕБУЕТ:** кризисный беат финала (не обязан кончаться гибелью, но решает выбор сезона).

**Старт S1: Лига 0 / Эльза 0 / ЗОВ 0** (первое видение = Эльза +5, ЗОВ +1 - завязка).
