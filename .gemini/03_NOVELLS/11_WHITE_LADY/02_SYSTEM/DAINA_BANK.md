# 🎵 БЕЛАЯ ДАМА - БАНК ДАЙН-ЭПИГРАФОВ

Заготовки строф В ДУХЕ латышских дайн (короткие, фольклорные, природа+истина) для сигнатуры «Дайна-эпиграф» (см. VOICE_LOCK). Ставятся курсивом в начале поста; смысл «отзывается» в сцене.
*Примечание: это стилизованные заготовки. При наличии - заменять подлинными латышскими дайнами с переводом (под спойлером). Дополнять банк по ходу.*

---

## ⚖️ О СУДЬБЕ (Лайма) - сцены выбора
- *Лайма нить мою прядёт, / у воды клубок ведёт: / где порвётся - там и брод, / где завяжется - там лёд.*
- *Доля ходит по росе, / достаётся не совсем; / смелый сам свой узел вьёт, / робкий ждёт, что Лайма ткёт.*
- *Спросишь Лайму - промолчит, / в гладь озёрную глядит; / что покажет та вода, / то и доля, то и да.*

## 🌊 О ВОДЕ/ОЗЕРЕ (Мать Озера) - перед явлением Эльзы
- *Мать Озёрная не спит, / белым полотном лежит; / что возьмёт - не отдаёт, / разве имя позовёт.*
- *Тихо озеро, как стол, / а под ним - холодный дол; / кто на дне венок плетёт, / тот живых наверх зовёт.*
- *Не ходи к воде в туман: / там не берег, там обман; / кто отыщет в ней лицо - / обручится в кольцо.*

## 💞 О ЛЮБВИ/ЛИГО (венок) - романтика
- *Я плела венок из ржи, / милый, имя завяжи; / по воде венок пущу - / за кем сплыл, того ищу.*
- *В ночь на Лиго папоротник / разом друг и разом сводник; / кто найдёт огонь-цветок, / тот любви возьмёт залог.*
- *Два костра на берегу, / я тебя не сберегу: / либо в пламя, либо в гладь - / сердцу надвое не стать.*

## 🕯 О МЁРТВЫХ/ВОЗВРАТЕ (Велю) - мистика/раскрытия
- *В Велю время гость придёт, / за столом не ест, не пьёт; / ты поставь ему хлеб, ковш - / и узнаешь, кто ты сплошь.*
- *Мёртвый правды не таит, / он у двери постоит; / что живые погребли, / то вернётся из земли.*
- *Кто оболган да утоплен, / тот водою не утолён; / имя верни ему назад - / отойдёт, и будет сад.*

## 🏚 О РОДЕ/УСАДЬБЕ/НАСЛЕДИИ
- *Дом без правды - что без крыши: / дождь идёт, а род всё ниже; / назови, кто согрешил, - / и поднимется стропил.*
- *Старый герб на воротах ржав, / у него тяжёлый нрав; / не наследство - тяжкий долг: / кто возьмёт - тот сам умолк.*

## 🌫 О ТУМАНЕ/ГРАНИ - пороги, между мирами (мотив блока I «туман над водой»)
- *Где туман на воду лёг, / там ни берег, ни порог; / ступишь раз - и сам не свой, / между явью и водой.*
- *Туман имя не таит, / он его себе берёт; / кто в тумане окликал, / тот себя и потерял.*
- *Разойдётся бель к утру - / что увидишь, не совру: / либо берег под ногой, / либо та, что над водой.*

## 🗝 О ИМЕНИ/ВОЗВРАТЕ ДОЛГА - раскрытия, упокоение
- *У воды два берега, / у вины - два имени: / что при людях сказано / и что в ил положено.*
- *Не цветами сходит грех, / а возвратом имени: / назовёшь - и тает снег, / промолчишь - и стынет всё.*

*Не удалять. Подбирать эпиграф по теме сцены (судьба→выбор, вода→Эльза, любовь→романс, Велю/имя→раскрытие, туман→пороги блока I). Пополнять по 2-3 за дев-слот; при наличии - заменять подлинными дайнами с переводом под спойлером.*
