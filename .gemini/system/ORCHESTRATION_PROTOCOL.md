# 🎼 ORCHESTRATION PROTOCOL V1.0 (The Trinity Chain)

Этот протокол описывает взаимодействие Gemini CLI, Claude Code и Local Llama для производства контента высшего качества.

## 🔄 ЦЕПОЧКА ПРОИЗВОДСТВА:

### ЭТАП 1: GEMINI (Архитектор)
- **Функция:** Сбор сырых данных (база, новости, лор).
- **Контроль:** Проверка соответствия "Библии" проекта.
- **Выход:** Текстовый каркас (Outline).

### ЭТАП 2: CLAUDE (Литературный Редактор)
- **Инструмент:** `./ask-claude.sh`
- **Функция:** Огранка стиля, придание тексту "глубины" и "киношности".
- **Пресеты:**
  - **YV_AUTHORITY:** Холодный, экспертный стиль Bloomberg.
  - **AL_MARGINALIA:** Пленочная эстетика, рефлексия, текстуры.
  - **EY_SCENARIO:** Психология, Dark Academia, Amber Age.

### ЭТАП 3: LLAMA (Генератор Вариантов)
- **Инструмент:** `./ask-local.sh`
- **Функция:** Массовка — 10+ вариантов заголовков, 5+ вариантов опросов, быстрые реакции NPC.
- **Выход:** Список альтернатив для выбора.

### ЭТАП 4: АУДИТ (System Agents)
- **Code Sentinel:** Техническая проверка (Markdown, JS).
- **Visual Director:** Генерация промпта Midjourney.
- **Lore Auditor:** Проверка на повторы и географию.
