# 🌌 ZODIAC - STATS RULES (числа со смыслом; залочено 04.07.2026, пакет предзапуска)

Числа двигаются ПО ПРАВИЛАМ, не на глаз. Каждое движение - в запись опроса (`POLL_LOG.json` завести при старте) и в STATE. Читателю числа не показываем напрямую - подсвечиваем образами («карта часа сегодня темнее»).

---

## 🕳 «ЭНТРОПИЯ» - СЧЁТЧИК ТРЕЩИНЫ (0-10, глобальная угроза сезона)

Насколько близко Зона Тишины к Пульсару / как быстро распадается ткань вероятностей вокруг героев. Аналог HEAT/ВЕРНОСТИ, но следит не организация - сама вселенная.

| Событие | Дельта |
|---|---|
| Герои решают конфликт силой/подавлением (метод Древних - форма/контроль) | +1 |
| Крупный всплеск неконтролируемой энергии Рождённого | +1 |
| Вмешательство фракций, ломающее баланс (ход SPS/Ордена/Близнецов) | +1 |
| «Неправильное» решение Рождённых (нестандартный путь - не сила и не контроль) | -1 |
| Акт настоящей связи между наследниками враждующих линий (романтика = шов трещины) | -1 |

**Пороги - ОБЯЗАТЕЛЬСТВА сюжета:**
- **3 - ПОМЕХИ:** карты часа начинают ошибаться (сигнатурный слой становится ненадёжным - механика голоса!).
- **5 - ЗОНА РЯДОМ:** Зона Тишины касается окраин Пульсара; одна комната-мир «глохнет».
- **7 - РАЗРЫВ:** кто-то из второстепенных Рождённых теряет связь со своим Древним прообразом.
- **10 - ТИШИНА:** кризисный беат финала сезона (Пульсар под угрозой поглощения).

**Старт сезона: ЭНТРОПИЯ = 2** (фон: трещина уже растёт, Древние молчат).

## 💞 AFFINITY / СОЗВУЧИЕ (по линии, 0-100)

Универсальная механика связи Рождённых (романтика и дружба - «созвучие частот»).

| Событие | Дельта |
|---|---|
| Линия открыта (первая совместная сцена сезона) | +5 |
| Заряжённый беат с героем | +3 |
| Выбор опроса в пользу героя | +5 |
| Выбор против героя (холод/дистанция) | -3 |
| Первое совместное «неправильное» решение (их энергии сложились) | +7 |
| Предательство/удар | -10 |

Пороги разблокировок: 25 Первая искра / 50 Общий резонанс (флешбек прообразов - 🔒 кусочек истории Древних!) / 75 Глубокое созвучие / 100 Единая частота (кап 99 до кульминации сезона).

**Старт:** все линии 0 (Малая Луна откроется в Главе 1-2 с +5).

## 🎛 РАЗНООБРАЗИЕ ОПРОСОВ (типы - ротировать, как во всех работах; `feedback_poll_types`, канон `03_NOVELLS/09_GENERAL/POLL_ENGAGEMENT_PLAYBOOK.md`)

Не один тип 2 Главы подряд. В `POLL_LOG.json` проставлять `type`.

**СЮЖЕТНЫЕ/выбор (двигают числа+сюжет, ПРИМЕНЯЮТСЯ):**
| Тип | Пример для ZODIAC | Двигает |
|---|---|---|
| **Действие** (база) | «как Рождённый гасит всплеск - силой или нестандартно» | сюжет + ЭНТРОПИЯ (нестандарт -1) |
| **Ставка/цена** | «раскрыть свою частоту фракции ради союза - да/нет» | риск героя |
| **К кому** | фокус линии созвучия | affinity линии |
| **Ценностный** | «форма Древних или свой путь» - ось наследника | характер |
| **Темп** | «тихо переждать или бить по Зоне» | ЭНТРОПИЯ |
| **Дилемма** | оба хода растят трещину | «третий путь» |

**ВОВЛЕКАЮЩИЕ (без дельты по замыслу, НЕ применяются к числам):**
- **Предсказание/теория:** «чья карта часа солжёт первой?» - мистерия трещины, оплата позже.
- **Квиз-лор:** «какой Древний прообраз у этого знака?» - геймификация лора (не 🔒-секреты).
- **Реакц-нудж:** залоченный набор эмодзи = тон следующей Главы. **Реакц-порог:** «N реакций → теневой слот».

## 📐 ДИСЦИПЛИНА

- Каждая закрытая Глава: пересчитать ЭНТРОПИЮ+affinity, записать в STATE + POLL_LOG.
- Пороги ЭНТРОПИИ - обязательства: достигли 5 - Зона касается Пульсара, не откладывается.
- Дельты вне таблиц - только с пометкой «вне правил: почему».
- **Сюжетные опросы применяются, ни один не теряется** (`feedback_all_polls_used`); вовлекающие - без числа. Проверка `stats-check.py zodiac` poll-audit.
