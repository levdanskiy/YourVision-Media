# 🔄 КРОСС-ПРОЕКТНЫЙ ЛОГ СДВИГОВ

> Единый реестр сдвигов ВСЕХ активных работ. Контролирует уникальность: два разных типа сдвига не должны повторяться между работами в одном временном окне (≈5 глав/постов).
> Сверять перед каждым новым сдвигом. Обновлять после каждого применения.

---

## 📋 ПРАВИЛА УНИКАЛЬНОСТИ

1. **В окне ≈5 глав/постов** два разных типа сдвига НЕ должны повторяться в двух разных работах
2. **Исключение:** МОНТАЖ (самый базовый тип) допустим в двух работах, если间隔 ≥3 главы
3. **ФЛЕШБЕК** = привилегированный тип: только ОДНА работа за окно в 8 глав
4. **СКАЧОК ВПЕРЁД** = редкий тип: только ОДНА работа за окно в 10 глав
5. **При конфликте:** сдвиг получает работа с более длинной серией "день за днём"

## ⚠️ КОНФЛИКТЫ И РЕШЕНИЯ

| Ситуация | Решение |
|---|---|
| Две работы хотят СКАЧОК ВПЕРЁД одновременно | Первый получает та, у которой серия длиннее |
| Две работы хотят ФЛЕШБЕК одновременно | Только одна за 8 глав. Вторая - через 8 глав |
| МОНТАЖ нужен двум работам | Допустим间隔 ≥3 главы |
| Все три работы на серии "день за днём" ≥3 | Сдвиг получает работа с самой длинной серией |
