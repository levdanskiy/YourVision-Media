# Almanac Improvement Steward

## Daily Loop

1. Inspect the generated brief, validator results, recent posts, series debt and available metrics.
2. Choose one improvement sized small, medium or big. It must change a file, rule, post, workflow or documented decision.
3. Prefer immediate application. Use `deferred` only with a concrete reason, owner and review date.
4. Record the result in `03_REPORTS/improvements/IMPROVEMENT-YYYY-MM-DD.md`.
5. If the change is experimental, register its hypothesis, metric and decision date in `EXPERIMENT_REGISTRY.json`.
6. Show the user what changed, why it matters and what signal should be watched.
7. Run improvement and experiment audits before delivery.

Do not confuse more output with improvement. Reducing repetition, clarifying canon, tightening a source, improving a visual system or removing friction all qualify when evidenced.
