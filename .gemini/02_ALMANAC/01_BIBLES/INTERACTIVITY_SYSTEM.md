# INTERACTIVITY SYSTEM

Almanac uses interaction as editorial listening, not engagement bait.

From `2026-07-07`, service interaction lives in `SERVICE_AND_SPECIALS.md`.
Core `AL` rhythm remains three daily posts; `SV` service notes and rare `SP`
specials are optional overlays, not a fourth daily post.

## Position

Interactive elements should make the reader observe, compare, choose, or remember something concrete from the post. They should not ask for generic approval, identity labels, or viral reactions.

Good interaction feels like a field note:

- Which object did you notice?
- Which smell exists near you today?
- Which technique fails most often?
- Which calendar version did you grow up with?

Bad interaction feels like growth hacking:

- Do you like this?
- Save/share/comment.
- Which one are you?
- Tag someone.

| Type | Frequency | Where |

| Quiz | Max 1 per month | `SV QUIZ` or native quiz poll; teaches a source/fact, not identity. |

## Poll Types

### 1. Field Poll

Use when the post names observable things.

```text
📊 Что реально есть рядом сегодня?
Иван-чай / Сено / Смола / Ягоды
```

### 2. Technique Poll

Use for food and recipe posts.

```text
📊 Что чаще всего ломается в тарте?
Ягода течёт / Крем плывёт / Корж мокрый / Глазурь комками
```

### 3. Direction Pulse

Use monthly to steer the channel without letting the audience flatten the project.

```text
📊 Что усилить в следующем месяце?
Мифы и тёмные оригиналы / Еда и техники / Календари и ритуалы / Оракулы и суеверия
```

### 4. Comparison Poll

Use when geography, calendars, or variants are part of the post.

```text
📊 Какой слой интереснее продолжить?
24 июня / 7 июля / Травы / Огонь и вода
```

### 5. Reader Field Note

Use as `SV READER-NOTE`, not as a daily `AL` replacement.

```text
Что в вашей семье считали плохой приметой на кухне?
```

Then treat answers as leads:
- verify dates, texts, ritual claims, and food safety before using them;
- anonymize unless explicit permission exists;
- do not publish private medical, religious, legal, romantic, or family-conflict details.

### 6. Weekly Oracle Note

Use as `SV ORACLE-NOTE`.

```text
Карта недели: Колесо Фортуны.
Оракул недели - не приказ, а карта внимания.
```

Allowed:
- real forecast format as editorial object: zodiac week, tarot week, omen week, rune/I Ching/moon week;
- 12 zodiac signs once per month, one short line each, without high-stakes claims;
- day/week/month tone through one card, sign, omen, rune, hexagram, or moon phase;
- reflective action;
- source/source family if the system is named.

Forbidden:
- "вам выпадет", "звёзды советуют", "точно случится";
- medical, financial, legal, romantic, fertility, death, fate advice;
- dependence or fear: "срочно", "опасность", "карты требуют";
- aggressive personalization that imitates a private consultation.

### 7. Micro Quiz

Use as `SV QUIZ` or as a native quiz poll when Telegram mechanics are useful.

```text
Один вопрос:
Что в таро исторически появилось раньше?
Козыри игры / Египетская тайная книга / Газетный гороскоп

Ответ: козыри игры.
```

Rules:
- one question only;
- one short answer reveal;
- source/fact/calendar/technique mechanism;
- max once per month.

### 8. Calendar Radar

Use as `SV CALENDAR-RADAR`.

```text
На этой неделе: 4 календарных узла.
```

Rules:
- 3-7 items;
- exact date system when relevant;
- full `AL CALENDAR/FEAST/MODERN` post only for the strongest item;
- verify factual dates before publication.
- if moon sighting, local religious authority, timezone, or regional calendar matters, say that the date varies.

## Forbidden Polls

- Personal prediction polls in `DIVINATION`.
- Polls in `SOURCE`, `LORE`, `FRAGMENT`, `HERITAGE`, `CALENDAR`, `CHRONOS`, unless the post is a separate monthly service note.
- Polls that ask the reader to rank cultures, countries, peoples, or religions.
- Polls that ask for medical, financial, legal, romantic, or fate-based advice.
- Polls with an obvious correct answer.

## Modernity Rules

Modern style is not slang. It is structure:

- strong searchable noun in the first two lines;
- one concrete hook;
- short blocks that can become carousel slides;
- source or mechanism early;
- one screenshotable kicker;
- visual prompt as evidence photo;
- interaction as observation, not begging.
