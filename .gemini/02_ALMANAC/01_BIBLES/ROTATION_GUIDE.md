# ROTATION_GUIDE - ПОСТОЯННАЯ РОТАЦИЯ РУБРИК
# Не привязано к месяцу. Действует всегда.

---

## СЛОТЫ

```
10:04 → ТЕМА II: МИФЫ      (#LORE / #SOURCE / #OMENS / #FRAGMENT)
15:04 → ТЕМА I: ВЫПЕЧКА    (#CAKES / #BUNS / #PATISSERIE / #RECIPE / #LISTS / #WORKFLOW)
18:02 → ТЕМА III: ПРАЗДНИКИ (#WHEEL / #CALENDAR / #HERITAGE / #CHRONOS)
```

**Правило трёх:** 3 поста каждый день, без исключений. Один слот пропущен = весь день битый.

---

## РОТАЦИЯ ПО ДНЯМ НЕДЕЛИ

### ТЕМА I - Выпечка (15:04)

| День | Рубрика |
|------|---------|
| Пн | #CAKES |
| Вт | #BUNS или #PATISSERIE |
| Ср | #RECIPE |
| Чт | #CAKES или #PATISSERIE |
| Пт | #BUNS |
| Сб | #CAKES |
| Вс | #LISTS или #WORKFLOW |

### ТЕМА II - Мифы (10:04)

| День | Рубрика |
|------|---------|
| Пн | #LORE |
| Вт | #SOURCE |
| Ср | #OMENS |
| Чт | #LORE или #SOURCE |
| Пт | #SOURCE |
| Сб | #LORE |
| Вс | #FRAGMENT ← обязательно раз в неделю |

### ТЕМА III - Праздники (18:02)

Привязана к реальному календарю:

| Ситуация | Рубрика |
|----------|---------|
| Ближайшие 3-4 дня до точки Круга | #WHEEL |
| Актуальный праздник на неделе | #CALENDAR |
| Региональный / умирающий ритуал | #HERITAGE |
| По умолчанию | #CHRONOS |

---

## ЖЁСТКИЕ ПРАВИЛА (НЕЛЬЗЯ НАРУШАТЬ)

**1. ТРИ ПОСТА В ДЕНЬ.** 10:04 / 15:04 / 18:02 - каждый день, включая выходные и праздники. Пропуск слота = брак.

**2. FRAGMENT КАЖДОЕ ВОСКРЕСЕНЬЕ.** Слот 10:04. Без исключений. Если воскресенье особенное (саббат, праздник) - FRAGMENT остаётся, особенность уходит в другой слот.

**3. LISTS МАКСИМУМ 1 В НЕДЕЛЮ.** Только воскресенье, слот 15:04. Чаще - обесценится.

**4. HERITAGE 1-2 В НЕДЕЛЮ.** Минимум 1 (рубрика не должна исчезать), максимум 2 (избегать концентрации, ностальгизация утомляет). Между двумя HERITAGE-постами должен быть минимум один день перерыва.

**5. БАЛАНС ГЕОГРАФИИ HERITAGE.** На 4 поста HERITAGE - не более 1 балтийского. Остальные 3 - другие регионы мира.

---

## ДОПОЛНИТЕЛЬНО: FRAGMENT-СЧЁТЧИК

Каждый 7-й пост архива - #FRAGMENT, независимо от темы и слота. Счётчик ведётся по общему числу опубликованных постов. На практике обычно совпадает с воскресеньем 10:04 (3 поста × 7 дней / 3 = каждое воскресенье).

## БАЛАНС ТЕМ (цель на месяц)

| Тема | Рубрики | Постов в месяц | % |
|------|---------|----------------|---|
| Выпечка | CAKES + BUNS + PATISSERIE + RECIPE | 12-14 | 40% |
| Мифы | LORE + SOURCE + OMENS + FRAGMENT | 10-12 | 35% |
| Праздники | WHEEL + CALENDAR + HERITAGE + CHRONOS | 7-9 | 25% |
| Сервис | LISTS + WORKFLOW | 3-4 | входят в Выпечку |

## ЧАСТОТА ПО РУБРИКАМ

| Рубрика | Частота |
|---------|---------|
| #CAKES | 2-3 раза в неделю |
| #BUNS | 1-2 раза в неделю |
| #PATISSERIE | 1 раз в неделю |
| #RECIPE | 1 раз в 2 недели |
| #LISTS | 1 раз в неделю (только воскресенье) |
| #WORKFLOW | по мере появления протокола (не чаще раза в неделю) |
| #LORE | 2 раза в неделю |
| #SOURCE | 2 раза в неделю |
| #OMENS | 1 раз в неделю |
| #FRAGMENT | 1 раз в неделю (каждое воскресенье) |
| #WHEEL | перед каждой точкой Круга (8 раз в год) |
| #CALENDAR | 1-2 раза в неделю |
| #HERITAGE | 1-2 раза в неделю (см. жёсткие правила) |
| #CHRONOS | по умолчанию когда нет привязки к дате |
