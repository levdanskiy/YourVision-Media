## 7 ВОПРОСОВ

**1. Формат**
- [ ] Только дефисы (-), ни одного эм-тире (—)
- [ ] Кавычки «ёлочки», не "лапки"
- [ ] Visual Prompt без MJ-флагов (--ar --v --style --s)

**2. Финал**
- [ ] Нет вывода-морали ("это учит нас...", "важно понимать...")
- [ ] Нет хэппи-энда без цены
- [ ] Пост заканчивается на образе, вопросе, или тишине — не на объяснении

**3. Рубрика**
- [ ] Соблюдена структура рубрики (см. ARCHIVE_TEMPLATE.md)
- [ ] Все обязательные блоки на месте (ЛЕГЕНДА / ТЕОРИЯ / АРХЕТИП и т.д.)

**4. Голос**
- [ ] Нет YV-лексикона: резонанс, директорат, хайп, котировки, чарт
- [ ] Нет пустых прилагательных: прекрасный, удивительный, особенный
- [ ] Нет spiritual-слов без контекста: гармония, энергетика, вибрация

**5. Специфика рубрики**

| Рубрика | Что проверить |
|---------|--------------|
| #LORE | Есть лингвистический слой (содержательный)? Есть тёмный слой (конкретный поступок)? Ритуальное действие физически выполнимо? Если есть современный перенос - архетип совпадает точно, не приблизительно? |
| #SOURCE | Первая строка - прямая цитата с годом? Есть блок "что скрыто"? |
| #OMENS | Есть физический механизм (не мистика)? Есть современный эквивалент? |
| #FRAGMENT | Максимум 5 предложений? Только материальный объект? Финал - тишина, не вопрос? |
| #CAKES/#BUNS/#PATISSERIE | Голос тактильный и тёплый (не академический)? Есть ЛЕГЕНДА? Есть сенсорные маркеры (звук+запах)? |
| #RECIPE | ТЕОРИЯ описывает молекулярный/химический механизм? Три ошибки объясняют ПОЧЕМУ? |
| #CHRONOS | Всё в настоящем времени? Финальное действие физическое (не намерение)? |
| #CALENDAR | Минимум 3 культуры? Есть блок МАРШРУТ? Если большой праздник - запланированы 2 поста? |
| #HERITAGE | Есть блок УТРАТА (без ностальгии - документация)? Финал - вопрос читателю? |
| #LISTS | Есть ПРИНЦИП ОТБОРА (ограничивающий, не описательный)? Есть ИСКЛЮЧЕНИЕ? |
| #WORKFLOW | Тон разговорный - показывает через образ, не объясняет зачем? |

**6. Опросы (только для #LISTS, #CAKES, #OMENS)**
- [ ] Стоит ли добавить опрос? (макс 1 в неделю на весь канал)
- [ ] Если да: варианты конкретные, из текста поста, без очевидно правильного ответа?

**7. Визуал**
- [ ] Промпт соответствует рубрике (см. VISUAL_SYSTEM.md)
- [ ] Нет людей, текстов, логотипов в описании
- [ ] Заканчивается на `shot on 35mm film Kodak Portra 800`

## БЫСТРАЯ ПРОВЕРКА GRADE

| Признак | Grade |
|---------|-------|
| Удивляет. Читается дважды. Финал держит тишину. | **S** |
| Все элементы. Сильный образ. Чистый финал. | **A** |
| Работает. Один элемент слабее. | **B** |
| Формально верно. Нет неожиданности. | **C** |
| Пересказ. Мораль. Запрещённые слова. | **F → переписать** |
