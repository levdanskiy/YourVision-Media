# RUBRIC TAXONOMY

This is the short source of truth for Almanac rubrics. Detailed writing rules live in `RUBRIC_RULES.md`.

## Global Principle

Almanac has no home city, country, or region. Geography is used when it is a factual property of the subject: origin, ritual context, ingredient ecology, text history, calendar practice, language, institution, route, or comparison.

Do not delete country or city names by default. They are useful when readers can compare versions, dates, ingredients, rituals, or source histories. What is forbidden is anchor framing: writing as if one city, country, region, latitude, or timezone is the channel's natural center.

Through `2026-07-22`, all three themes are global by default. Myths/tales/omens, desserts/baking/bread, and calendars/rituals/time must be researched across the whole world: Africa, the Americas, East Asia, South Asia, Southeast Asia, Central Asia, West Asia, Oceania, Europe, Arctic/North, island cultures, diasporas, and modern internet/global systems. No region is the default lens.

From `2026-07-23`, Almanac is recipe-only. The same global standard remains, but the daily object is always a recipe. Myth, calendar, divination, etymology, holidays and source texts become context layers inside recipes, not standalone `AL` rubrics.

Monthly planning must avoid familiar-source gravity. If a month leans heavily on one cultural zone, the next planning pass must compensate with underrepresented zones.

## 100% Coverage Standard

Every complete post must answer six questions:

1. **What is the object?** One subject, named precisely.
2. **Where is the evidence?** Source, tradition, date, technique, or observable fact.
3. **How does it work?** Mechanism: narrative, material, social, linguistic, astronomical, chemical, or ritual.
4. **What is hidden?** Dark layer, loss, anxiety, power structure, failure mode, or forgotten function.
5. **Why now?** Calendar, season, slot, current relevance, or reader-facing reason.
6. **Where does it land?** Final image, question, action, or silence. No moral.

## 09:04 - Myths, Tales, Legends, Omens, Divination

Legacy through `2026-07-16`: `10:04`.
Active as standalone daily slot through `2026-07-22`. From `2026-07-23`, `09:04` becomes a prep/base recipe slot and uses only food rubrics.

| Rubric | Use For | Do Not Use For |
|--------|---------|----------------|
| `LORE` | Myth, fairy tale, legend, parable, urban legend, archetype. | Authored literature with a known text. |
| `PERSONAE` | Living dossier for a myth, fairy-tale, legendary, saintly, or folkloric figure. | Generic biography, fan retelling, or psychological type without source. |
| `BESTIARY` | Mythic beings, monsters, helpers, familiars, animal-spirits, boundary creatures. | Ordinary animals without folklore function. |
| `OBJECTS` | Magical, ritual, protective, cursed, sacred, or story-driving objects. | Decorative props without narrative or ritual function. |
| `SOURCE` | Authored text: book, poem, play, essay, exact quote. | Folk stories without an authorial text. |
| `OMENS` | Omens, superstitions, folk prohibitions, signs, protective gestures, household rules. | Pure magic claims without anthropological reading. |
| `DIVINATION` | Tarot, astrology, horoscopes as media/history, oracle systems, I Ching, runes, lots, cowrie shells, geomancy, dream books, coffee grounds, palmistry, Ifa. | Predicting the reader's future, giving personal advice, or presenting magic claims as fact. |
| `FRAGMENT` | One material object, maximum compression, silence. | Concepts, living beings, explanations. |
| `ETYMON` | Word origin as cultural archaeology. | Decorative etymology without a source. |

### 09:04 Full Coverage

| Rubric | Required For 100% |
|--------|-------------------|
| `LORE` | Specific myth/tale/legend + named tradition/source family + linguistic layer + dark/original layer + structural reading + non-moral final. |
| `PERSONAE` | Figure + source corpus + dossier facts + relationships/objects/routes + hidden function + modern survival without claiming literal reality. |
| `BESTIARY` | Creature + source tradition + habitat/boundary + behavior/rules + fear or protection mechanism + modern echo. |
| `OBJECTS` | Object + source/tradition + material/form + rule of use + power/cost + where the same object-function survives now. |
| `SOURCE` | Exact work + author + year + short quote + context of concealment/pressure + one stylistic observation + precise present-day echo. |
| `OMENS` | Folk wording + type (omen/superstition/prohibition/protective gesture) + physical/social/anxiety mechanism + cross-cultural or modern equivalent + no validation of magic. |
| `DIVINATION` | System/object + historical source + material method + symbolic grammar + social/psychological function + clear non-predictive framing. |
| `FRAGMENT` | One material object + sensory contact + implied memory/loss + maximum 5 sentences + silence at the end. |
| `ETYMON` | Word + language/source + first use or reconstructed form + cognates/semantic drift + why the word matters now. |

## 15:04 - Food Only: Desserts, Baking, Bread, Foodways

For new and rewritten posts from `2026-07-07`, every 15:04 post must be directly tied to food: dish, drink, ingredient, preservation, table, cooking technique, kitchen tool, food history, or edible ritual. `PROSE` and `ETYMON` do not occupy 15:04 as standalone rubrics; food language or literary references must be embedded inside a food rubric.

From `2026-07-23`, this food-only rule expands to all three daily `AL` slots. Every allowed rubric below must carry a reproducible recipe or protocol with ingredients and preparation.

### Sweet Branch

| Rubric | Use For | Core Test |
|--------|---------|-----------|
| `CAKES` | Cakes and large layered desserts. | Architecture of occasion. |
| `BUNS` | Sweet buns, enriched dough, yeasted sweet formats. | Dough rhythm and warmth. |
| `PATISSERIE` | Technical pastry, baked miniatures, French/European pastry logic. | Precision and technique. |
