# BOLD LAYER ROADMAP

Effective from `2026-07-17`.

This roadmap locks the bold layers currently approved for Almanac. From
`2026-07-23`, all layers must serve `ALMANAC: TABLE` and recipe-only publishing.

| Layer | System File | First Use |
|-------|-------------|-----------|
| Recipe menu radar / prep service | `RECIPE_ONLY_SYSTEM.md`, `SERVICE_AND_SPECIALS.md` | Replaces standalone oracle/radar from `23.07`. |
| Micro quiz | `SERVICE_AND_SPECIALS.md`, `INTERACTIVITY_SYSTEM.md` | One pilot by end of July or first half of August. |
| Stories | `STORY_LAYER_SYSTEM.md` | Start from `17.07` with 1-2 weekly frames. |
| Proof of work | `PROOF_OF_WORK_SYSTEM.md` | Required for high-risk posts from `17.07`. |
| Reader as archive | `READER_ARCHIVE_SYSTEM.md` | Pilot prompt in August. |
| Monthly album/PDF | `MONTHLY_ALBUM_SYSTEM.md` | July album pilot after July closes. |

---

## Operating Rule

When preparing any date from `17.07` onward, the agent must check:

1. Does this day need a proof receipt?
2. Is there recipe-service debt or a useful menu/prep note?
3. Is there a story frame worth planning?
4. Is there a reader archive lead to collect or avoid?
5. Does this post create a candidate for the monthly album?

Do not use all layers every day. The boldness comes from selection.
