# 📋 ШАБЛОНЫ ПОСТОВ ALMANAC (V3.0)

📍 Один шаблон на группу рубрик. Следовать точно.
📍 Финал поста — самое важное. Не заполнять механически.
📍 Современная подача V4 применяется ко всем шаблонам: см. `CONTEMPORARY_STYLE_GUIDE.md`.

---

## ОБЯЗАТЕЛЬНАЯ V4-АНАТОМИЯ

Любой новый пост должен выдерживать четыре формата: Telegram caption, carousel script, screenshot quote, searchable archive entry.

Минимальная структура:

```text
[Hook / object / quote]

[Evidence block: источник, дата, место как факт объекта, материал, техника]

[Mechanism block: как это работает физически, социально, ритуально или исторически]

[Hidden layer: утрата, тревога, власть, ошибка, вытесненный оригинал]

[Modern echo: один конкретный now-point, если он точный]

[Kicker line]

→ [action/question/silence]
```

Правила:
- место не становится оптикой канала; оно появляется только как факт предмета, источника, техники или обряда;
- один современный якорь максимум;
- один searchable noun в заголовке или первых строках;
- никаких engagement bait;
- блоки должны раскладываться на 5-7 слайдов без переписывания.
