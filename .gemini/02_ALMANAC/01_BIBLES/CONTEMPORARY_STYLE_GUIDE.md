# CONTEMPORARY STYLE GUIDE

This guide translates current social/content trends into Almanac rules. It does not replace `VOICE_LEXICON.md`, `VISUAL_SYSTEM.md`, or `RUBRIC_RULES.md`.

## Position

Almanac should feel current, but not trend-chasing. The tone is:

- human, not brand-polished;
- proof-led, not opinion-led;
- tactile, not generic aesthetic;
- serialized, not random;
- globally literate, not Western default;
- designed for saves, shares, search, and screenshots.

Geography rule: keep names of countries, cities, regions, languages, and communities when they support comparison or evidence. Remove only default-center phrasing: «у нас», «наш регион», «здесь принято», or any repeated habit that makes one place the channel's implied home.

## 2026 Signals To Use

These are working editorial rules distilled from current social/content trend reports and design coverage. They are not permission to chase every platform fad.

| Signal | Almanac Translation |
|--------|---------------------|
| Human-led storytelling | Include one precise human/practitioner detail when it genuinely proves experience. |
| Authenticity over polish | Keep small asymmetries, material detail, field-note texture. Do not over-smooth. |
| Serialized content | Build recurring mini-series and numbered arcs across weeks. |
| Social search | Use clear searchable nouns in titles and first lines: object, tradition, date, technique. |
| Community over virality | Ask questions that invite memory or observation, not generic engagement. |
| Editorial carousels | Structure posts so each block can become one slide without rewriting. |
| Lo-fi / film / analog | Favor evidence-like images: flash, grain, scan, worn surface, imperfect crop. |
| Proof-based trust | Every surprising claim gets a source trail, number, date, or material test. |

Trend basis:
- Sprout Social, `7 Social Media Trends to Know in 2026`: serialized content, community over virality, human-led storytelling, social search.
- FINN Partners, `What to Expect from Social Media Platforms in 2026`: search, short-form, community, creator-led authenticity.
- Creative Bloq, 2026 illustration/typography trend coverage: human touch, imperfection, crafted texture.
- Digital Camera World, 2026 photography trend coverage: less perfection, more story, analog feeling.
- Current carousel design coverage: editorial carousel structure, mobile-first type, one idea per slide, saves/shares logic.

## What To Avoid

- Trend mimicry: slang, meme grammar, fake casualness.
- Overdesigned luxury food styling.
- Generic “dark academia” visuals without evidence.
- AI-smooth images that look too perfect.
- AI-generic claims: "ancient wisdom", "people have always", "in many cultures" without a named source or mechanism.
- Engagement bait: “tag someone”, “which one are you”, “save this”.
- Empty relatability: “we all know this feeling”.
- Viral hooks that are not strictly true.

For polls and audience questions, use `INTERACTIVITY_SYSTEM.md`. Interaction should increase observation and editorial feedback, not pressure readers to perform engagement.

Visuals should now read as modern editorial/documentary magazine work: controlled light, tactile evidence, clean composition, and a specific object or process. Avoid stock-photo beauty, fantasy illustration, museum reconstruction, or generic atmosphere.

## Authorial Position

The channel speaks as a careful field editor: curious, source-bound, tactile, and willing to say when a claim is uncertain.

Use first-person experience only when it proves something concrete:
- a kitchen failure;
- a field observation;
- a source-checking note;
- a correction.

Do not turn the channel into autobiography. The authorial voice is responsibility, not confession.

## Anti-Slop Rule

Before a post is marked `ГОТОВ`, it must contain at least three of these:
- named source or edition;
- original term, date, material, or technique;
- sensory marker that can be checked;
- failure mode or hidden cost;
- exact reason for today's publication;
- visual prompt that shows evidence, not atmosphere.

If the post could be generated from a generic encyclopedia paragraph, rewrite it.

## Post Anatomy V4

Every post should be able to survive as:

1. Telegram caption.
2. Carousel script.
3. Screenshot quote.
4. Searchable archive entry.

Recommended structure:

```text
[Hook / object / quote]

[Evidence block: source, date, place, material, technique]

[Mechanism block: how it works]

[Hidden layer: loss, anxiety, power, failure, omitted original]

[Modern echo: one concrete now-point]

[Kicker line]

→ [action/question/silence]
```

## Hooks

Use one of five hook types.

| Type | Use When | Example Shape |
|------|----------|---------------|
| Object hook | Physical object leads. | `A mirror can be a trap before it becomes a symbol.` |
| Source hook | A quote or exact source opens the post. | `“...” - author, year.` |
| Contradiction hook | The fact reverses expectation. | `This is not a love story. It is a storage system for grief.` |
| Mechanism hook | Process is the surprise. | `The bread rises because bacteria outwork the clock.` |
| Calendar hook | Date is the engine. | `Today is not the holiday. It is the hinge before it.` |

Rules:

- Hook must be true.
- Hook must name the object within 1-2 lines.
- No vague “you won’t believe” energy.
- No fake universality.

## Kicker Lines

A kicker is the line people screenshot. It should be short, factual, and slightly tilted.

Good:

- `The ritual did not disappear. The room it needed disappeared.`
- `Sugar remembers heat better than we remember instructions.`
- `A superstition is a risk assessment with no instruments.`
- `The calendar is not neutral. It tells the body what to wait for.`

Bad:

- `And that is why this matters today.`
- `Maybe we should all learn from this.`
- `This ancient wisdom is still relevant.`

## Carousel-Ready Block Rules

Even if publishing only to Telegram, write so the post can become a carousel:

- 5-7 blocks maximum.
- Each block has one job.
- Headings should be concrete, not decorative.
- One key number/date/source per post, not five.
- One visual object per post.
- Kicker line should work alone.

Carousel slide map:

| Slide | Content |
|-------|---------|
| 1 | Hook + object. |
| 2 | Source/evidence. |
| 3 | Mechanism. |
| 4 | Hidden layer. |
| 5 | Modern echo. |
| 6 | Kicker + question/action. |

## Searchability

Add searchable nouns naturally:

- myth/person/object: `Arachne`, `Anansi`, `Inanna`, `mochi`, `injera`, `Obon`;
- category: `trickster`, `underworld`, `sourdough`, `lunar calendar`, `superstition`;
- date or source: `1595`, `ATU 510A`, `UNESCO`, `solstice`.

Do not stuff keywords. One precise noun is enough.

## Visual Direction V4

Visuals should look like evidence, not decoration.

Use:

- analog flash on one object;
- documentary crop;
- macro texture;
- archival scan / table / worn paper;
- imperfect hand/process frame;
- deep negative space;
- restrained editorial composition;
- one consistent color temperature per post/series.

Avoid:

- luxury stock food;
- perfect flat lays;
- generated fantasy scenes with too many symbols;
- fake ancient manuscripts with unreadable text;
- over-saturated “cinematic fantasy”;
- people posing.

## Interaction Without Engagement Bait

Ask questions that produce memory, not comments for comments’ sake.

Good:

- `→ What object in your kitchen has no known origin?`
- `→ Which household rule did you inherit without explanation?`
- `→ What bread in your family belongs to a day, not a recipe?`

Bad:

- `→ Do you agree?`
- `→ Comment below.`
- `→ Which one are you?`

## Final Rule

Modern does not mean louder. Modern means clearer evidence, sharper hooks, stronger structure, more global sampling, more human texture, and less polished emptiness.
