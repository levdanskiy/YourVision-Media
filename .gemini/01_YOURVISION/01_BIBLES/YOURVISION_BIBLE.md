# YOURVISION: ГЛОБАЛЬНЫЙ МЕДИА-ПРОТОКОЛ (V6.0)

**Миссия:** Ультимативная экспертиза сезона Евровидения 2026.
**Тон:** Elite Insider (Bloomberg x Dazed). Сухие факты + острая аналитика. Никакой восторженности.
**Язык:** Русский основной. Украинский — по флагу рубрики. Английский — только в терминах и цитатах.

---

## ТЕХНИЧЕСКИЙ СТАНДАРТ

**Пунктуация:** Только короткие дефисы (-). Длинное тире — никогда.

**Слова-табу:** невероятный, потрясающий, ошеломительный, легендарный, уникальный, эпический, грандиозный.

**Эмодзи:**
- В теле поста: ЗАПРЕЩЕНЫ.
- Флаги стран (🇦🇹, 🇺🇦 и т.д.): разрешены везде.
- Иконки рубрик в заголовке (🧬 🧪 🏛 🎯 📊): только один раз, только в h1.
- В метаданных и тегах: свободно.

**Валидация:** Обязательный прогон через pre_audit.py перед публикацией.

---

## СИСТЕМА ОЦЕНКИ: ИНДЕКС ВЕНЫ

Каждый артист получает пять оценок от 0 до 10:

| Критерий | Что оценивается |
|---|---|
| **Вокал** | Чистота, диапазон, контроль, эмоциональная передача |
| **Постановка** | Сценография, хореография, свет, управление пространством Stadthalle |
| **Novelty** | Оригинальность, запоминаемость, неожиданность решений |
| **Televote** | Массовое соединение, хуки, момент, доступность |
| **Jury** | Артистизм, сложность, профессиональная подача |

**Индекс Вены = среднее арифметическое × 2 = 0-100 баллов.**

### Грейды

| Грейд | Баллы | Значение |
|---|---|---|
| **A** | 80-100 | Elite. Публикуется без правок. |
| **B** | 60-79 | Solid. Публикуется с минорной правкой. |
| **C** | 40-59 | Weak. Требует переработки секций. |
| **D** | < 40 | Fail. Перезапись с нуля. |

| Язык | [яз] | [яз] |
