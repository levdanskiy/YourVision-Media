# 📋 ЧЕК-ЛИСТ «ВЫЗВАТЬ КРУГ НА [ДАТА]»

Стандартный протокол для запуска круга ЛЮБОЙ новеллы. Выполнять ПОСЛЕ получения запроса «Запусти круг на [дата]» и ДО написания постов.

---

## 🔍 ПЕРЕД НАПИСАНИЕМ (ОБЯЗАТЕЛЬНО)

### 0. Время в нарративе (ОБЯЗАТЕЛЬНО ПЕРЕД НАПИСАНИЕМ)
- [ ] **Глава ≠ День.** Время течёт своим чередом. Скачки вперёд/назад допустимы.
- [ ] **Варьировать темп:** где-то 1 глава = 1 день, где-то 1 глава = несколько дней, где-то 1 день = несколько глав.
- [ ] **Не топтаться:** сюжет должен продвигаться, не стоять на месте.
- [ ] **Единица измерения:** «Глава N» (не «День N»). Сдвиги могут быть в любой момент.
- [ ] Касается ВСЕХ проектов без исключения.

### 1. Результаты опросов (если высланы)
- [ ] Проверить: выслал ли пользователь результаты опросов перед кругом
- [ ] Если да — ОБЯЗАТЕЛЬНО использовать при написании главы
- [ ] Результаты опросов = триггер для сюжетных поворотов

### 1. Процентуальное появление героев
- [ ] Запустить `appearance-count.py` для проекта
- [ ] Показать полный список героев с % появления
- [ ] Отметить: кто отстаёт, кого вернуть, кто НЕ ПОЯВЛЯЛСЯ ни разу
- [ ] **Все герои из CHARACTER файлов ДОЛЖНЫ появиться** хотя бы раз за сезон
- [ ] Добавить отстающих в ближайшие главы

### 2. Статы любовных линий
- [ ] Проверить текущие значения affinity по STATS.json
- [ ] Проверить пороги разблокировок (25/50/75/100)
- [ ] Если достигнут порог → запланировать ДОПОЛНИТЕЛЬНЫЙ пост (лор/сцена)
- [ ] Обновить RELATIONS.md / MATRIX.md

### 3. Общие статы новеллы
- [ ] Проверить основные счётчики (ВЕРНОСТЬ, HEAT, ЭНТРОПИЯ и т.д.)
- [ ] Проверить пороги (3/5/7/10)
- [ ] Если достигнут порог → запланировать ДОПОЛНИТЕЛЬНЫЙ пост
- [ ] Обновить STATE.md

### 4. Типы опросов
- [ ] **Перечень типов:** сюжетный, ценностный, ставка/цена, к кому/романтический, темп, дилемма, предсказание/теория, реакц-нудж, реакц-порог, квиз-лор
- [ ] Проверить `ENGAGEMENT_USAGE_LEDGER.md` — какие типы использовались较少
- [ ] Выбрать тип по минимуму использования или циклично
- [ ] **НЕ повторять один тип 2 главы подряд**
- [ ] Подготовить 2-4 варианта ответов (мульти-селект допустим)

### 5. Саундтреки
- [ ] Проверить SOUNDTRACK-лог за последние 7 дней (ВСЕ 6 проектов!)
- [ ] **ТРЕК-УРОВЕНЬ:** одна песня — раз в 7 дней
- [ ] **АРТИСТ-УРОВЕНЬ:** не повторять 2 поста подряд / не чаще 1 раза в 4-5 Глав
- [ ] **КРОСС-ПРОЕКТНО:** трек, использованный в другом проекте, нельзя 7 дней
- [ ] Выбрать трек из палитры проекта,	match тон Главы
- [ ] Обновить SOUNDTRACK-лог

### 6. Синопсис + план сезона
- [ ] Прочитать SEASON_1_OUTLINE.md / SEASON_2_ROADMAP.md
- [ ] Сверить: где мы в сезоне/блоке
- [ ] Проверить: какой тип клиффа был прошлым (ротация)
- [ ] Проверить: открытые 🔒-локи и что можно/нельзя раскрывать
- [ ] Проверить: кто давно не получал сцену/опрос

### 7. План дня (до 3 вариантов на слот)
- [ ] Для КАЖДОГО временного слота подготовить до 3 вариантов
- [ ] Формат: краткое описание (1-3 предложения)
- [ ] Указать: какой герой/сцена, какой опрос, какой саундтрек
- [ ] Отправить на утверждение ДО написания

### 8. Время в нарративе
- [ ] **Одна глава НЕ равна одному дню.** Сюжет НЕ должен топтаться.
- [ ] **Время СВОИМ чередом:** таймскипы ВПЕРЁД И НАЗАД. Единица - «Глава N» (не «День N»).
- [ ] **Скачки допустимы:** воспоминания, прыжки в будущее/прошлое.
- [ ] **Один день может длиться несколько глав.** Одна глава может длиться несколько дней.
- [ ] **Главы идут друг за другом, НЕ как дни.** Это роман, не календарь.

## ✍️ ПРИ НАПИСАНИИ

### 8. Лимиты слов и типы постов
*   **Лимиты слов (строго):**
    | Тип поста | Лимит |
    |-----------|-------|
    | Промо | 300-400 слов |
    | Завязка/аннотации | 600-700 слов |
    | Story/клифф | 800-900 слов |
    | Лор/реакц | 500-600 слов |
*   **Интеграция опросов:** Опросы и другие интерактивные элементы встраиваются непосредственно в тело постов истории, а не публикуются отдельными сообщениями на канале.
*   **Форматы выборов:** Включать стандартные опросы, а также интерактивные посты с выбором через реакции-эмодзи (эмодзи-выбор).
*   **Первый пост дня проекта (Анонс/Нарративный итог):**
    *   Всегда служит анонсом на день и отражает результаты предыдущего голосования.
    *   **Запрещено** прямое подведение итогов (например, «В опросе победил вариант 2»). Результаты голосования выражаются исключительно **через повествование** в тексте поста.

### 9. Промпт
- [ ] **ОБЯЗАТЕЛЬНО в КАЖДОМ посте**
- [ ] Формат: `[Grade]` + `[Prompt]` + `[Frame X:Y]`
- [ ] Проверить VOICE_LOCK проекта (ARCANA = `Prompt:`, не `Visual Prompt:`)
- [ ] Нет Midjourney-флагов (--ar, --v, --style)
- [ ] Имена героев в промпте (если есть в кадре)

### 10. Проверки после каждого поста
- [ ] Лимит слов (проверить)
- [ ] CJK иероглифы (проверить)
- [ ] **🖼 Frame ratio** — НЕ ПОВТОРЯТЬ один и тот же ratio на канале чаще, чем через 5 постов
- [ ] Английский в прозе (проверить)
- [ ] Дефис вместо тире
- [ ] Граф перед написанием (graphify query)

## 📊 ОТЧЁТ (9 ЭЛЕМЕНТОВ)

После написания всех постов отправить отчёт:

1. **Посты/длина/промпты/саундтреки** — таблица по слотам
2. **Опросы/типы/ротация** — какие типы использованы, что выбрать
3. **Герои/% по ВСЕМУ сезону** — таблицаappearance-count
4. **Статы/пороги/долги** — что обновлено, какие пороги достигнуты
5. **Трекеры** — cast-appearance, cadence, secret-ledger
6. **Саундтрек-лог/нарушения** — ВСЕ 6 проектов, нет повторов
7. **Промо ВСЕХ работ** — статус промо-кампаний
8. **Виды промо-постов** — что использовано, что ещё не Developed
9. **Что сделано / что делать дальше** — итог + следующий круг

## ⚠️ КРИТИЧЕСКИЕ ПРАВИЛА

- **Опросы закрываются в 20:00** (универсальное правило).
- **Результат опроса НЕ обязан появиться сразу** — он встаёт в повествование тогда, когда по сюжетному плану должна быть соответствующая сцена.
- **Интеграция интерактива:** Опросы и выборы идут вместе с постами истории, а не публикуются отдельно.
- **Первый пост проекта** — анонс дня и нарративное отражение итогов голосования (без прямых упоминаний процентов/вариантов).
- **Лимиты постов в день:** В активные дни проекта публикуется установленное количество постов (например, 7 для Eleyia/Kingmaker, 5 для ARCANA/ZODIAC/Хроник, 3 для Stories).
- **Время течёт свободно** — не привязывать внутреннее время сюжета к датам публикации.
- **Сигнатуры проектов не смешивать** (Вкус момента = только Eleyia).
- **Не указывать время чтения** — нигде, ни в одном проекте библиотеки.
