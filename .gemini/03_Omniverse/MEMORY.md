## Stories rules
- Третий POV, кроме проектных исключений.
- Слова: завязка 600–700, story/клифф 800–900, лор/реакц 500–600.

## Literature rules
- Глава целево 3500–4000 символов, общая чтения 20+ мин.
- Не больше 3 глав подряд `глава=день`, потом монтаж/скачок/флешбэк.
- Каст: все заведённые появляются, перед новым именем grep, новый = bible до коммита.
- Пары открыты во всех работах.
- Опросы ротируются по типам: сюжетные/выбор, предсказание/квиз/реакц-нудж/реакц-порог/дилемма.
- QA: voice-lint + stats-check + чек-лист перед коммитом.

## Chronicles rules
- **Формат:** CHRONICLES (10 сезонов по 100 глав).
- **Лимиты:** story 800-900 слов, архив 500-600 слов, промо 300-400 слов.
- **Архивные посты:** каждые 10 глав (артефакт: карта, дневник, ноты).
- **Механики:** Память Рода (0-100%), Резонанс, Шёпот Струны.
- **Кросс-лор:** Возможен в Сезонах 8-10 (контакт с вампирами/ведьмами).
- **Эстетика:** Магический реализм. Пыль, костры, дерево, металл. Никаких спецэффектов.
- **Промпты:** Имена персонажей ДОСЛОВНО из CHARACTERS.md. Эпоха = сезон.
- **Саундтрек:** Classical + Folk + Dark Ambient. Не повторять артиста 2 поста подряд.

## Image/Voice rules
- Платформа Reve.
- Формула промпта: character tag + scene + lighting + quality tags + Frame X:Y.
- Базовые теги: Photorealistic, 8k, cinematic style, Kodak Portra 800, high contrast shadows.
- Всегда `No text, no logos`.
- Только дефис в прозе, русские заголовки.
