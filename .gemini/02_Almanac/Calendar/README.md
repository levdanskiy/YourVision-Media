# Almanac: Calendar

Глобальная энциклопедия праздников, кругов года и пороговых состояний.
Праздник как организующий принцип: от Дня Независимости до Самхейна, от Обона до Карнавала.

Пять постов в день: приметы, духи, практики, мифы, календарь.

Бренд: **Almanac** (зонтик) → Table (рецепты) + Calendar (праздники).
Канал: https://t.me/AlmanacCalendar

## Слоты
- 11:45 - АВРОРА: знаки, приметы, фрагменты, дивинация, astrology/forecast
- 15:15 - АНИМА: существа, люди, архетипы, пантеоны, духи, heritage/folk
- 17:15 - ПЕРЕХОД: практики, тела, ритуалы, маски, сны, инициации
- 20:15 - КАНУН: циклы, память, поминовение, календарные рубежи, предвестия

## Особенности
- Четыре поста в день с 23.07.2026
- Серийные посты #SEQUENCE по пятницам и воскресеньям (2-4 поста на одну тему)
- Глобальная география без культурного центра
- Никакой еды, рецептов, бытовой кулинарии
- Гадание и forecast допустимы как культурная/символическая оптика, без медицины, денег, фатализма и имитации личной консультации

## Структура
- `01_BIBLES/CHANNEL_CANON.yaml` - канон проекта
- `01_BIBLES/RUBRIC_RULES.md` - рубрики по слотам
- `01_BIBLES/RUBRIC_GLOBAL_DEPTH.md` - глобальная глубина рубрик по континентам
- `02_CONTENT/` - ежедневные посты по датам
- `03_REPORTS/` - редакционные отчёты
- `04_DATABASES/` - реестры публикаций, серий, канона
- `tools/` - валидаторы и скрипты

## Команды

Аудит ротации рубрик и тем:

```bash
python3 tools/audit_rotation.py 2026 07        # один месяц
python3 tools/audit_rotation.py 2026 07 --week 28  # одна неделя
python3 tools/audit_rotation.py                 # вся история
```

Аудит серий:

```bash
python3 tools/audit_series.py
```

Валидация структуры:

```bash
python3 tools/validate_lexicon.py
```
