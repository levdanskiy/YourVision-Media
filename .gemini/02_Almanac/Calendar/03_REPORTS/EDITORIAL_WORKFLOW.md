# EDITORIAL WORKFLOW - LEXICON

## Ежедневный цикл
1. Подготовка поста за день до публикации
2. Проверка по PRE-PUBLISH_CHECKLIST.md
3. Публикация в слот 11:45 / 15:15 / 17:15 / 20:15
4. Запись в PUBLICATION_REGISTRY.json
5. Обновление CONTENT_INDEX.csv

## Серийные посты #SEQUENCE
- Планируются минимум за неделю
- Одна серия = один объект
- Длина 2-4 поста
- Начинается в любом подходящем слоте
- Продолжается по тому же графику
- Между сериями минимум 2 дня обычных постов

## Непрерывное улучшение (Continuous Improvement)
Система работает в автономном режиме, выполняя фоновые задачи:

**Ежедневно:**
- Поиск и внедрение мелких фишек для постинга в Telegram.
- Развитие лора канала, улучшение текущих тем и рубрик.
- При необходимости: веб-поиск и сбор материалов/информации.

**Каждые 5 дней:**
- Анализ глобальных трендов (tone-of-voice, эстетика, новые стили для промптов Midjourney).
- Внедрение трендовых визуальных приемов.
- Предложение крупных стратегических улучшений для канала.
