# STATUS MODEL - LEXICON

## Статусы записи
- draft: черновик, не готов
- ready: готов к публикации
- scheduled: запланирован
- published: опубликован
- archived: перемещён в архив
- corrected: исправлен после публикации

## Жизненный цикл серии #SEQUENCE
1. draft
2. planned (серия спланирована)
3. publishing (посты выходят)
4. complete (серия завершена)
