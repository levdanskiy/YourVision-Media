# ROTATION STATUS REPORT

This is not a separate user task. It is an obligatory editorial step before writing any new day of posts.

When the user asks to prepare posts for a date, the agent must:
1. Check what has already been prepared in the current month.
2. Report briefly what rubrics, food branches, service notes, cultural zones, and formats have already appeared.
3. Name the current debts and the next moves.
4. Proactively change the requested date's rubrics, genre, lens, or format when balance requires it.
5. Then write the posts.

Every 5 prepared days, add the trend revision panel from `TREND_REVIEW_CADENCE.md` before the posts as well.

Do not wait for the user to ask for rotation control separately.

## Visual User-Facing Report

Before the posts, include a compact visual dashboard, not a paragraph.

```text
Rotation dashboard before [date]

| Блок | Уже есть | Недобор / риск | Решение на дату |
|------|----------|----------------|-----------------|
| 09:04 | [dominant rubrics] | [missing rubrics/lenses] | [chosen rubric + mode] |
| 15:04 | sweet [n], savory [n], broad [n] | [branch debt] | [chosen food branch] |
| 21:04 | [dominant rubrics] | [missing evening formats] | [chosen rubric + lens] |
| Coverage | [zones represented] | [zone debt] | [zone/axis closed today] |
| Service | [SV/SP this week] | [overuse risk] | [none/SV/SP, not daily] |

Format decision:
| Slot | Rubric | Mode | Why |
|------|--------|------|-----|
| 09:04 | [...] | FIELD FILE / SOURCE CARD / LORE | [...] |
| 15:04 | [...] | LAB NOTE / FOODWAYS / RECIPE | [...] |
| 21:04 | [...] | TABLE MAP / CALENDAR / CHRONOS | [...] |
```

Keep it short. It should make the decision visible at a glance and must fit before the posts without becoming a full audit.

If the date is a 5-day trend-review trigger, add this second compact panel:

```text
Trend revision - [date]

| Signal | What matters now | Almanac move |
|--------|------------------|--------------|
| [...] | [...] | [...] |
| [...] | [...] | [...] |
| [...] | [...] | [...] |

Feature applied now:
| Size | Feature | Slot/date |
|------|---------|-----------|
| small / medium / big | [...] | [...] |
```

Use status words instead of vague prose:
- `OK` - balanced enough;
- `WATCH` - not broken, but drifting;
- `DEBT` - must be corrected soon;
- `CLOSE TODAY` - the requested date will close it.

## What The Agent Must Track

### Slots

From `2026-07-17`:
- `09:04` - myth/source/omens/divination/personae/bestiary/objects/prose/etymon.
- `15:04` - food only.
- `21:04` - calendar/ritual/time/feast/modern/rites/cycles.

Legacy through `2026-07-16`: `10:04 / 15:04 / 18:02`.

### Food Balance

Track three food branches:
- sweet: `CAKES`, `BUNS`, `PATISSERIE`, `DESSERTS`, `SWEETS`;
- savory baking: `BREAD`, `FLATBREAD`, `PIES`;
- broad food/process: `FERMENT`, `PRESERVE`, `SOUP`, `CONDIMENTS`, `RECIPE`, `FOODWAYS`, `PANTRY`, `DRINKS`, `TOOLS`, `WORKFLOW`, `LISTS`.

If sweet dominates, move the next 15:04 to savory or broad food unless the date strongly demands dessert.

### Morning Balance

Do not let `LORE` and `SOURCE` crowd out:
- `PERSONAE`;
- `BESTIARY`;
- `OBJECTS`;
- `OMENS`;
- `DIVINATION`;
- `ETYMON`;
- rare `PROSE`.

If the month lacks dossier energy, choose `PERSONAE`, `BESTIARY`, or `OBJECTS` and write it as a modern field file.

### Evening Balance

Do not let `CHRONOS` become the default forever. Actively rotate:
- `CALENDAR`;
- `HERITAGE`;
- `CYCLES`;
- `MODERN`;
- `RITES`;
- `FEAST`;
- `WHEEL` when a solar threshold approaches.

If a date has food + holiday overlap, prefer `FEAST` at 21:04 and keep 15:04 as technique/food object.

### Global Coverage

Every report must check whether the month is leaning too heavily on familiar canons.

Priority debts to close:
- Africa / African Diaspora;
- Indigenous Americas;
- Oceania / Island Cultures;
- South Asia / Southeast Asia;
- Central Asia / West Asia when absent;
- Global Modern.

Country/city names are allowed as evidence, comparison, source, technique, language, or route. They are not allowed as the channel's default home voice.

## Bolder Editorial Decisions

The agent is expected to be bolder than the plan when the plan is flat.

Allowed:
- replace a generic `CHRONOS` with `FEAST`, `RITES`, `MODERN`, or `CYCLES`;
- replace a repeat `CAKES` with `SOUP`, `PRESERVE`, `CONDIMENTS`, `DRINKS`, or `FLATBREAD`;
- replace a broad `LORE` with `PERSONAE`, `BESTIARY`, `OBJECTS`, `TABOO`, `DREAM`, or `FIELD FILE` lens;
- add a native poll inside one suitable AL post if weekly cadence allows;
- add an `SV` only if it helps navigation or listening, not as a fourth daily post;
- add an `SP` only for major thresholds, usually `18:04` after `2026-07-17`.

Forbidden:
- adding a fourth daily `AL` post;
- changing published/prepared legacy days only for slot aesthetics;
- flattening global coverage because one familiar zone is easier;
- using trendiness as slang or fake casualness.

## Tone Upgrade

Use more courage in:
- first lines: sharper, more cinematic, more object-led;
- structure: dossier, field file, evidence board, lab note, source card, table map;
- visual prompts: modern editorial/documentary evidence, not pretty illustration;
- endings: precise question, physical action, or clean silence.

Modern/trendy means: stronger editorial shape, clearer evidence, more tactile visuals, more confident selection. It does not mean meme slang.
