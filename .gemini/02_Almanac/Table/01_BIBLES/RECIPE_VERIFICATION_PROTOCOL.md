## 🔬 МЕТОДОЛОГИЯ ПРОВЕРКИ

Перед написанием любого рецепта я провожу верификацию через интернет-поиск:

### 1. Техника и пропорции

**Что проверяю:**
- Правильная ли влажность теста (80% для фокаччи, 60% для пиццы)
- Температура и время (холодная ферментация = 12–24 часа в холоде)
- Пропорции соли (обычно 2–3% от веса муки)
- Соотношение жидкостей и сухих ингредиентов

**Пример поискового запроса:**
```
sourdough hydration percentage autolyse recipe authentic
focaccia 80% cold fermentation technique
```

### 2. Химия процессов

**Что проверяю:**
- При какой температуре идёт реакция Майяра (140–160°C)
- Как работает осмос при мацерации ягод
- Физика эмульсии (майонез: желток + масло, размер капель)
- Почему тесто растёт (дрожжи + сахар → CO2 + этанол)

**Пример поискового запроса:**
```
Maillard reaction temperature meat crust science
osmosis maceration berries sugar extraction
emulsion mayonnaise droplet size stability
```

### 3. История и этимология блюд

**Что проверяю:**
- Откуда пришло название (tiramisu = "подними меня" на диалекте Тревизо)
- Когда появилось (1960s–70s, регион Тренто/Венето)
- Оригинальные ингредиенты vs современные вариации
- Региональные отличия (не все "карбонара" — настоящая без сливок)

**Пример поискового запроса:**
```
tiramisu origin history name meaning region
carbonara authentic recipe no cream history
paella valenciana traditional ingredients rabbit
```

### 4. Культурная вариативность

**Что проверяю:**
- Настоящая паэлья = кролик + курица + бобы (не морепродукты)
- Региональные особенности (Валенсия vs Барселона)
- Сезонность блюд (октябрь — время для оливкового сбора)
- Традиционные сочетания

## 🔍 ПРИМЕРЫ ПРОВЕРКИ

### Пример 1: Фокачча

**Шаг 1: Поиск техники**
```
Query: "focaccia recipe 80 hydration cold proof authentic ligurian"
Source: Serious Eats, King Arthur Baking, итальянские кулинарные сайты
```

**Верифицировано:**
- Влажность 80% — правильная для мягкой фокаччи
- Холодная ферментация (12–24 часа) — традиция Лигурии
- Углубления (dimples) — для удержания оливкового масла
- Пропорция соли: 2–3% от веса муки

**Шаг 2: Проверка истории**
```
Query: "focaccia origin history name etymology"
Source: Oxford Companion to Food, итальянские источники
```

**Верифицировано:**
- Название от "focus" (очаг, лат.) — flatten bread on hearth
- Регион: Лигурия (Genoa)
- Древний римский корень: panis focacius

### Пример 2: Тирамису

**Шаг 1: Поиск истории**
```
Query: "tiramisu origin history disputed 1960 1970 tresto veneto"
Source: Accademia del Tiramisù, кулинарные историки
```

**Верифицировано:**
- Появился в 1960s–70s, регион Тренто/Венето (не древний рецепт!)
- Название: "tira mi su" = "подними меня" на диалекте
- Оригинальные ингредиенты: savoiardi, mascarpone, яйца, кофе, сахар
- Безликёрные версии — традиционные; с marsala/amarretto — вариации

**Шаг 2: Проверка техники**
```
Query: "tiramisu cream stability no eggs pasteurization safety"
Source: Food science,serious eats
```

**Верифицировано:**
- Яичные белки не нагреваются (сырые) — использовать пастеризованные
- Крем не должен быть жидким ( mascarpone + пена белков)
- Время выдержки: минимум 6 часов (желательно ночь)

### Пример 3: Паэлья

**Шаг 1: Поиск аутентичности**
```
Query: "paella valenciana authentic ingredients rabbit snails no seafood"
Source: Valencia tourism, BBC Good Food, испанские шефы
```

**Верифицировано:**
- Настоящая паэлья Валенсиана = кролик + курица + бобы + улитки
- Паэлья с морепродуктами = паэлья Маринера (другая традиция)
- Рис: короткозёрный (bomba/arborio), неBasmati
- Социбуш (socarrat) — поджаренная корочка, нужна!

**Шаг 2: Проверка техники**
```
Query: "paella socarrat technique heat distribution authentic"
Source: Spanish cuisine experts
```

**Верифицировано:**
- Широкая плоская сковорода (paella pan) — для испарения
- Не мешать после закладки риса!
- Высокий жар первые 10 мин, затем низкий

| "Карбонара со сливками" | Настоящая карбонара = гуанчиале, пекорино, яйцо, чёрный перец |
| "Тирамису — древний рецепт" | Появился в 1960s–70s, не старинный! |
| "Паэлья с креветками — аутентично" | Настоящая паэлья Валенсиана — с курицей и кроликом |
| "Фокачча как пицца" | Фокачча — толстая, масляная; пицца — тонкая, без масла в тесте |
| "Хлеб на "быстрых дрожжах" — лучше" | Закваска (sourdough) — старая техника, более сложный вкус |
| "Майонез в блендере" возможен | Может не схватиться! Нужно по каплям масло |
