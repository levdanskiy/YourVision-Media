# TREND REVIEW CADENCE

This is an obligatory workflow, not an optional research task.

Starting from `2026-07-17`, every 5 prepared publication days the agent must do a visible trend revision before sending posts to the user.

The user does not need to ask for it separately.

## Trigger

Run the trend revision:
- before the first new-time day: `2026-07-17`;
- then before every 5th prepared day: `2026-07-22`, `2026-07-27`, `2026-08-01`, `2026-08-06`, etc.;
- also after a major platform/content shift if discovered while working.

If several days are prepared at once, do the revision before the first day in that 5-day block.

## What To Check

Use current trend research, not memory, when the user asks for trend revision or when the 5-day trigger fires.

Check at least three surfaces:
- social/content: Telegram, creator economy, social search, communities, short-form, carousels;
- visual/design: editorial photography, anti-AI craft, texture, typography, motion, image aesthetics;
- food/culture/media: food trends, folklore/history media, slow content, newsletters, audio/video formats.

Prefer primary or reputable industry sources. Save source names/links in the working note or final answer when used.

## User-Facing Trend Panel

Before posts, show a compact visual panel:

```text
Trend revision - [date]

| Signal | What changed / what matters | Almanac move |
|--------|-----------------------------|--------------|
| [trend 1] | [short finding] | [what we add/change] |
| [trend 2] | [short finding] | [what we add/change] |
| [trend 3] | [short finding] | [what we add/change] |

Decision:
| Size | Feature | Apply where |
|------|---------|-------------|
| small / medium / big | [new feature] | [date/slot/rubric] |
```

The panel must be visible to the user. Do not hide it in internal reasoning.

## Implementation Rule

Every 5-day review must produce at least one concrete change:
- **small:** new hook type, new kicker pattern, a fresh poll type, a visual prompt detail, a micro-format;
- **medium:** new series name, new post shape, new service-note type, stronger visual system rule;
- **big:** slot/rubric rotation change, new recurring franchise, new distribution/audio/video workflow.

Do not only say "we should try". Choose one feature and apply it to the nearest suitable post.

## Boundaries

Allowed:
- bolder first lines;
- field-file / dossier / lab-note / table-map shapes;
- visual evidence prompts;
- mini-series names;
- native polls when cadence allows;
- `SV` for navigation/listening;
- `SP` for major thresholds only.

Forbidden:
- adding a fourth daily `AL` post;
- using slang as a substitute for editorial courage;
- chasing a trend that weakens sources, global coverage, or factual precision;
- turning divination into personal forecasts;
- making AI-polished visuals look generic.
