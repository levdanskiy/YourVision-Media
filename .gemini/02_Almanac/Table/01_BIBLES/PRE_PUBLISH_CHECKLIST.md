# ЧЕКЛИСТ ПЕРЕД ПУБЛИКАЦИЕЙ
# Прогнать для каждого поста перед финальным статусом ГОТОВ

Авторитетный автоматический gate: `python3 tools/almanac publish YYYY-MM-DD`. Он проверяет структуру, источники, continuity, visual prompt, смысловые повторы, статус публикации, реальные assets, claim-level evidence, эксперименты и инциденты.

**0A. Trend revision каждые 5 дней**
- [ ] Если дата попадает в 5-дневный триггер из `TREND_REVIEW_CADENCE.md`, перед постами показана visual trend panel
- [ ] Проверены свежие сигналы по content/social, visual/design и culture/food/media
- [ ] Предложены 2-3 новые фишки и выбрана минимум одна для немедленного применения
- [ ] Внедрение видно в ближайшем посте: новая форма, hook, visual detail, service idea, series/franchise или структурный приём
- [ ] Трендовость не стала сленгом, engagement bait или ослаблением фактов

**1. Формат**
- [ ] Только дефисы (-), ни одного эм-тире (—)
- [ ] Кавычки «ёлочки», не "лапки"
- [ ] Visual Prompt без MJ-флагов (--ar --v --style --s)
- [ ] Длина тела поста попадает в целевую рамку рубрики из `RUBRIC_RULES.md`; отклонение осознанное, не случайный недобор

**2. Финал**
- [ ] Нет вывода-морали ("это учит нас...", "важно понимать...")
- [ ] Нет хэппи-энда без цены
- [ ] Пост заканчивается на образе, вопросе, или тишине — не на объяснении

**3. Рубрика**
- [ ] Соблюдена структура рубрики (см. ARCHIVE_TEMPLATE.md)
- [ ] Все обязательные блоки на месте (ЛЕГЕНДА / ТЕОРИЯ / АРХЕТИП и т.д.)
- [ ] Пост проходит 100% coverage из `RUBRIC_TAXONOMY.md`: объект, доказательство, механизм, скрытый слой, почему сейчас, финал
- [ ] Источники соответствуют `SOURCE_DATABASES.md`: уровень доверия достаточный, цитата/ссылка/издание указаны
- [ ] Пост не усиливает региональный перекос месяца; культурная зона отмечена в плане или metadata
- [ ] География работает как факт, сравнение или источник, а не как домашний голос канала

**4. Голос**
- [ ] Нет YV-лексикона: резонанс, директорат, хайп, котировки, чарт
- [ ] Нет пустых прилагательных: прекрасный, удивительный, особенный
- [ ] Нет spiritual-слов без контекста: гармония, энергетика, вибрация

**5. Современная подача V4**
- [ ] Первая строка использует один честный hook type из `CONTEMPORARY_STYLE_GUIDE.md`: object / source / contradiction / mechanism / calendar
- [ ] Доказательство появляется в начале: источник, дата, материал, техника, число или наблюдаемый тест
- [ ] Пост можно разложить на 5-7 carousel-ready блоков без переписывания
- [ ] Есть один searchable noun в заголовке или первых строках: имя, объект, техника, дата, традиция, код типа ATU
- [ ] Если есть современный якорь, он один и конкретный; без общего "как сейчас в интернете"
- [ ] Kicker line короткий, фактический, пригодный для скриншота
- [ ] Anti-slop rule из `CONTEMPORARY_STYLE_GUIDE.md`: минимум 3 доказательных элемента, не generic summary
- [ ] Для факт-heavy постов виден proof-of-work: source receipt, date mechanism, translation note, technique test или object receipt
- [ ] Нет engagement bait: "комментируй", "сохрани", "какой ты", "отметь друга"
- [ ] Пост выглядит как современный editorial object, а не как школьное мини-эссе
- [ ] Если за последние два поста уже был классический essay-shape, этот пост использует Dossier Card / Field File / Lab Note / Table Map / Source Card / Micro-list
- [ ] Видимая структура помогает читать с телефона: короткие блоки, сильный kicker, один объект в центре

**6. Специфика рубрики**

| Рубрика | Что проверить |
|---------|--------------|
| #LORE | Есть лингвистический слой (содержательный)? Есть тёмный слой (конкретный поступок)? Ритуальное действие физически выполнимо? Если есть современный перенос - архетип совпадает точно, не приблизительно? |
| #SOURCE | Первая строка - прямая цитата с годом? Есть блок "что скрыто"? Есть один стилистический приём? |
| #OMENS | Это примета, суеверие, запрет или защитный жест? Есть физический/социальный/тревожный механизм (не мистика)? Есть современный эквивалент? |
| #DIVINATION | Для `AL`: это система символов/оракула, а не прогноз? Есть история, материал, грамматика, функция вопроса? Нет личных советов и фатализма? Для `SV ORACLE-NOTE`: есть FORMAT_SUBTYPE и соблюдены low-stakes границы? |
| #FRAGMENT | Максимум 5 предложений? Только материальный объект? Финал - тишина, не вопрос? |
| #ETYMON | Есть язык/праформа/первое употребление? Есть дрейф значения? Есть современный отзвук? |
| #CAKES/#BUNS/#PATISSERIE/#DESSERTS/#SWEETS | Это точно сладкая ветка? Голос тактильный и тёплый (не академический)? Есть ЛЕГЕНДА? Есть сенсорные маркеры? Для DESSERTS - ложка/холод/стабилизация; для SWEETS - сахарная стадия/текстура. |
| #BREAD/#FLATBREAD/#PIES | Это точно несладкая выпечка? Есть зерно/соль/огонь или начинка как центр? Есть технология, сенсорика готовности и культурная функция? |
| #FERMENT/#PRESERVE/#SOUP/#CONDIMENTS | Это точно широкая еда, а не слабый FOODWAYS? Есть механизм: живая культура / сохраняющий агент / жидкая среда / малая приправа? Есть сенсорная граница готовности и источник по технике? |
| #RECIPE | ТЕОРИЯ описывает молекулярный/химический механизм? Три ошибки объясняют ПОЧЕМУ? |
