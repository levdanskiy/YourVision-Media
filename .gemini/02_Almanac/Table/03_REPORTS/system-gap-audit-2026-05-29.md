## Новый контроль

Добавлен `tools/audit_system_docs.py`.

Команда:

```bash
python3 tools/audit_system_docs.py
```

Назначение:
- ловит старые рубричные формулировки в core-docs;
- ловит региональный якорь в source-of-truth;
- отдельно показывает исторические planning hits, которые нельзя переиспользовать без пересборки.
