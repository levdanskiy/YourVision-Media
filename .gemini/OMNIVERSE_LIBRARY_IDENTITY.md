## 📣 ПРАВИЛА ПРОМО В ФОРУМЕ

1. Промо новой работы живёт в топике «Анонсы» + в её СОБСТВЕННОМ новом топике (создаётся в начале промо-окна) - НЕ в топиках других работ. Старое правило линейного канала «доп-окна хвоста → промо следующей новеллы» внутри одного топика-новеллы остаётся допустимым только для работ ОДНОЙ серии по ротации (Orchid→Eleyia), кросс-серийного промо в чужих топиках нет.
2. Стандарт промо-окна - по образцу `03_NOVELLS/01_ELEYIA/02_SYSTEM/S2_PRELAUNCH_PLAN.md`: 5-9 дней (мост-рекап или анонс мира → досье героев → конфиг-опросы → механика-тизер → 🎵 трек → отсчёт с реакц-порогом → запуск с навигатором).
3. При каждом запуске/реактивации - перезакреп навигатора ГРУППЫ в топике «Анонсы» (карта топиков со статусами) по `NAVIGATOR_TEMPLATE.md`.
