## ОБЗОР

Правила для работы со статистикой проекта.

---

## СЧЁТЧИК ПЛАН

**Тип:** Возрастающий (0 → 10)
**Максимум:** 10
**Минимум:** 0

### Механика:
- **Растёт от:** восстановления отношений, общего языка (архитектура)
- **Падает от:** прошлого, ревности, обид, чужих детей

### Пороги:
- **0:** Марк уезжает, Лена остаётся одна
- **3:** Есть намёки на восстановление
- **5:** ДомAlmost достроен, отношения теплеют
- **7:** Дочь принимает Марка
- **10:** Дом построен, отношения восстановлены

### Опросы:
- ЧТО изменить в проекте дома?
- Добавить комнату из прошлого?
- Оставить как есть?
- Построить заново?

---

## ОБНОВЛЕНИЕ СТАТИСТИКИ

### После каждого поста:
1. Обновить `STATS.json`
2. Проверить `STATE.md`
3. Обновить `CHARACTERS.md` (если есть изменения)
4. Проверить `SOUNDTRACK.md` (если использован новый трек)

### Проверка:
- Значение счётчика в пределах 0-10
- История изменений корректна
- Нет дубликатов в использованных треках
- Баланс появления персонажей соблюдён

---

## ПРАВИЛА

1. **Обновлять после каждого поста** - не откладывать
2. **Проверять корректность** - значение в пределах min/max
3. **Не дублировать** - следить за историей изменений
4. **Кросс-проектно** - проверять треки и фреймы
