# 🏺 СТРАТЕГИЯ ALMANAC (V8.1)

📍 **Правило:** 2 поста обязательно, 3-й по ситуации.
📍 **Три темы — три временных слота.**

---

## 📅 РАСПИСАНИЕ

```
10:04 → ТЕМА II: МИФЫ
         #LORE / #SOURCE / #OMENS / #FRAGMENT

15:04 → ТЕМА I: ВЫПЕЧКА
         #CAKES / #BUNS / #PATISSERIE / #RECIPE
         + сервис: #LISTS / #WORKFLOW

18:02 → ТЕМА III: ПРАЗДНИКИ
         #WHEEL / #CALENDAR / #HERITAGE / #CHRONOS
```

---

## 🔄 РОТАЦИЯ РУБРИК

### ТЕМА I — Выпечка (15:04)
Еженедельная ротация между форматами:
```
Пн → #CAKES
Вт → #BUNS или #PATISSERIE
Ср → #RECIPE (глубокий разбор техники)
Чт → #CAKES или #PATISSERIE
Пт → #BUNS (тепло, пятница, домашнее)
Сб → #CAKES (повод, выходной)
Вс → #LISTS или #WORKFLOW (сервис)
```

### ТЕМА II — Мифы (10:04)
Еженедельная ротация:
```
Пн → #LORE (мировой миф)
Вт → #SOURCE (авторский текст, цитата)
Ср → #OMENS (примета)
Чт → #LORE или #SOURCE
Пт → #SOURCE
Сб → #LORE
Вс → #FRAGMENT ← обязательно раз в неделю
```

### ТЕМА III — Праздники (18:02)
Ротация по сезонной логике:
```
Привязана к реальному календарю:
- Близко к точке Круга → #WHEEL
- Современный праздник на неделе → #CALENDAR
- Региональный/умирающий ритуал → #HERITAGE
- Особый момент времени → #CHRONOS (по умолчанию)
```

---

## 💎 ПРАВИЛО FRAGMENT

Каждый 7-й пост архива — #FRAGMENT, независимо от темы и слота.
Счётчик ведётся по общему числу опубликованных постов.

## 🎯 ПРИОРИТЕТЫ НА МАЙ 2026

**Выпечка:** Сезонные ягоды. Ревень. Клубника. Техника французской меренги.

**Мифы:**
- Белтейн (1 мая) через #LORE — огни, скот, переход.
- SOURCE: Андерсен «Снежная королева» — метафизика холодного разума.
- OMENS: майские приметы погоды.

**Праздники:**
- #WHEEL: Белтейн — астрономия + ритуал + современность (1 мая).
- #CALENDAR: связь Дня труда и Белтейна — один архетип, разные эпохи.
- #HERITAGE: Юргис (Иванов день по-балтийски) — 23 июня близко.
- #CHRONOS: Синий час в мае (18:02 — самый долгий).

## ⚠️ ЧАСТЫЕ ОШИБКИ

| Ошибка | Как это выглядит | Правило |
|--------|-----------------|---------|
| LORE и SOURCE неотличимы | Оба начинаются с пересказа | SOURCE всегда начинается с цитаты |
| FRAGMENT слишком длинный | Больше 5 предложений | Закон: максимум 5 |
| CHRONOS — о прошлом | "В старину люди замечали..." | CHRONOS — только сейчас, настоящее время |
| CALENDAR без связей | Описывает один праздник | Минимум 3 культуры в одном посте |
| BAKERY без легенды | Сразу к рецепту | ЛЕГЕНДА обязательна, это первый блок |
| Мораль в финале | "Это учит нас, что..." | Запрещено во всех рубриках |
