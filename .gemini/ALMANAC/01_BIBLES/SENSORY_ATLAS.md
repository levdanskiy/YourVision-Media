# 🌊 АТЛАС ОЩУЩЕНИЙ (V2.0)
📍 **Балтийский лексикон для моделей Gemma 2 и Claude.**
📍 **Принцип:** Точность важнее красивости. Не "пахнет морем" — а что именно и как.

---

## 🥐 ВЫПЕЧКА — СЕНСОРНЫЙ СЛОВАРЬ

### Запахи

| Название | Описание | Когда использовать |
|----------|----------|-------------------|
| **Дрожжевое тепло** | Влажный, живой, чуть кисловатый. Запах поднимающегося теста в прохладной кухне. | Бриошь, булочки, хлеб — этап расстойки |
| **Сухое масло** | Ореховый, немного жжёный. Появляется когда масло карамелизуется. | Beurre noisette, песочное тесто |
| **Ванильный пар** | Сладкий, тяжёлый, стелется по полу. | Крем-патисьер, pannacotta |
| **Карамельный дым** | Острый, тёмный, с горчинкой. Граница между карамелью и пригоревшим. | Крем-брюле, тарт Татен |
| **Корица в холодном воздухе** | Пряный, согревающий, персидский. Интенсивнее в холоде, чем в тепле. | Осенняя выпечка, штрудель |
| **Цедра в тесте** | Острый, свежий, чуть горький. Отличается от цедры в сыром виде — тепло смягчает. | Лимонные тарты, мадлен |
| **Шоколадный туман** | Тёмный, тяжёлый, обволакивающий. Распространяется раньше, чем видишь источник. | Брауни, ганаш, горячий шоколад |

### Звуки

| Название | Описание | Когда использовать |
|----------|----------|-------------------|
| **«Крак»** | Сухой, звонкий, однократный. Карамель ломается. Тонкий лёд. Хрустящее тесто. | Проверка готовности карамели |
| **«Шип»** | Резкий, короткий. Масло встречает горячую сковороду. | Обжарка орехов, карамель |
| **«Бульк»** | Медленный, тяжёлый. Густой крем закипает. | Заварной крем, джем |
| **«Шорох»** | Мягкий, непрерывный. Мука просеивается. Сахарная пудра. | Финальный декор |
| **Тишина в духовке** | Когда бисквит готов — звук выпечки пропадает. Не таймер — тишина. | Момент готовности |

### Текстуры

| Название | Описание | Когда использовать |
|----------|----------|-------------------|
| **Мучная пыль** | Невесомая сухость на кончиках пальцев. Исчезает при нажатии. | Раскатка теста |
| **Живое тесто** | Тёплое, чуть липкое, с упругостью мышцы. Отличается от мёртвого (перебитого). | Дрожжевое тесто в момент готовности |
| **Холодное масло** | Твёрдое, почти стеклянное. Рассыпается при рубке. | Песочное тесто, круассаны |
| **Шёлк крема** | Без зёрен, без пузырей. Ложка оставляет след который медленно затягивается. | Готовый патисьер, ганаш |
| **«Дрожание»** | Центр тарта ещё двигается при лёгком встряхивании. Это правильно. | Момент вынуть из духовки |

## 🌿 ПРИРОДА — СЕНСОРНЫЙ СЛОВАРЬ

### Запахи по сезонам

#### Весна
| Название | Описание |
|----------|---------|
| **Мокрый чернозём** | Тяжёлый, живой, первородный. Первые +5°C в почве. |
| **Петрикор** | Геосмин — запах земли после первого дождя. Самый узнаваемый запах весны. |
| **Берёзовый сок** | Почти без запаха — только влажность и сладость. Апрель. |
| **Первые цветы** | Крокусы — холодный, почти пресный. Нарциссы — тяжёлый, театральный. |

#### Лето
| Название | Описание |
|----------|---------|
| **Трава в полночь** | Свежий, чуть горький хлорофилл. Усиливается к ночи. |
| **Морская соль и шиповник** | Запах побережья после шторма. Йод + дикая роза + влага. |
| **Зверобой на солнце** | Смолистый, медовый, чуть горький. Только в жару. |
| **Нагретый камень** | Минеральный, сухой. Появляется после 14:00 на юге. |

#### Осень
| Название | Описание |
|----------|---------|
| **Прелые листья** | Сладковато-гнилой. Не неприятный — земля перерабатывает. |
| **Первый иней** | Почти без запаха. Только холод и металл. |
| **Яблоки в подвале** | Тёплый, сброженный, домашний. |
| **Дым от листьев** | Горький, осенний. Не то же, что дым от дров. |

#### Зима
| Название | Описание |
|----------|---------|
| **Смола и хвоя** | Холодный, смолистый. Ель vs сосна — разные. Ель острее. |
| **Мороз на металле** | Почти нет запаха. Только сухость в носу. |
| **Дрова в печи** | Тёплый, берёзовый. Первые минуты горения — самые ароматные. |
| **Снег перед снегопадом** | Чистый, электрический. Появляется за 20-30 минут до снега. |

### Звуки природы

| Название | Описание | Момент |
|----------|---------|--------|
| **Тишина снега** | Снег поглощает звук. Мир сжимается. | Первый снегопад |
| **Лёд трескается** | Низкий гул, потом щелчок. | Март, оттепель |
| **Птицы до рассвета** | Начинают за 40 минут до первого света. | Летнее солнцестояние |
| **Ветер в соснах** | Непрерывный, многослойный. Не "шум" — органный регистр. | Береговой лес |
| **Дождь на горячем асфальте** | Шипение в первые секунды. Потом — ровный стук. | Летняя гроза |

## 🏠 ДОМ — СЕНСОРНЫЙ СЛОВАРЬ

### Запахи

| Название | Описание |
|----------|---------|
| **Разогретая медь** | Металлический, сухой. Старые дверные ручки, турка для кофе. |
| **Старое дерево** | Тёплый, чуть пыльный, без сырости. Выдержанная мебель. |
| **Льняная скатерть** | Почти нет запаха. Только чистота и крахмал. |
| **Воск свечи** | Медовый, нейтральный. Отличается от ароматической — проще, честнее. |
| **Книжная пыль** | Ванильный альдегид — бумага стареет. Старые книги пахнут ванилью. |
| **Кофе утром** | Горький, дымный. Первые 30 секунд помола — самые сильные. |

### Звуки

| Название | Описание |
|----------|---------|
| **«Пение крана»** | Низкий гул старых труб в вечерней тишине. Только когда дом успокоился. |
| **«Шуршание льна»** | Глухой, мягкий. Скатерть, постельное, занавеска. |
| **Тиканье** | Механические часы. Исчезает когда к нему привыкаешь — слышно только в тишине. |
| **Оседание дома** | Ночной треск балок и стен. Дерево реагирует на перепады температуры. |
| **Шаги на старом полу** | Каждая половица — своя нота. Карта дома через звук. |

### Текстуры

| Название | Описание |
|----------|---------|
| **Патина металла** | Гладкий, но холодный. Потемнел от времени и прикосновений. |
| **Льняное полотно** | Чуть жёсткое, не скользит. Тяжелее хлопка. |
| **Старое стекло** | Неоднородное. Пузырьки, волны. Изображение за ним чуть плывёт. |
| **Холодная керамика** | Утренняя кружка. Согревается медленно — это правильно. |

## ⏳ ВРЕМЯ — СЕНСОРНЫЕ МАРКЕРЫ

Как ощущается конкретный момент суток и года:

| Момент | Свет | Запах | Звук | Температура |
|--------|------|-------|------|-------------|
| **04:30 летом** | Серо-голубой, горизонтальный | Роса, холодная трава | Птицы — за 40 мин до света | Самая низкая за сутки |
| **Синий час (18:02)** | Индиговый, жидкий | Остывающий асфальт | Город стихает, но не смолкает | Начинает падать |
| **Час волка (3:00)** | Нет. Полная тьма | Ничего — воздух нейтрален | Тишина, потом один звук | Ниже нуля ощущений |
| **Первый гром** | Жёлто-зелёный перед ударом | Озон — металлический шёлк | Тишина, потом всё сразу | Давление падает |
| **Первый снег** | Белый снизу, серый сверху | Почти ничего. Только чистота | Город замолкает постепенно | Около нуля, без ветра |
| **Белтейн (1 мая рассвет)** | Золотой, косой | Молодая трава, дым | Птицы максимально активны | Тепло, но земля ещё холодная |
