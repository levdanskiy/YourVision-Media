# 🦙 Llama Bridge V2.0 (Локальный Спринтер)

Этот мост обращается к Llama 3.2 через Ollama (`./ask-llama.sh`). Работает офлайн, мгновенно, без внешних API.

## 🛠 КОГДА ИСПОЛЬЗОВАТЬ

- Генерация 10+ вариантов заголовков, названий, реакций (массовка).
- Быстрая проверка грамматики и стиля без задержек сети.
- Задачи с приватными данными (не должны покидать машину).
- Пресеты **YV_HEADLINES** и **EY_REACTIONS** из `bridge-controller`.
- Черновой штурм идей перед передачей в Claude или Mistral.

## 🚫 КОГДА НЕ ИСПОЛЬЗОВАТЬ

- Финальный текст поста — качество Llama недостаточно для публикации.
- Исторический и культурный контекст — это `mistral-bridge`.
- Технический код — это `deepseek-bridge`.
- Если нужны актуальные данные (Llama не знает текущих событий).

## 📞 ВЫЗОВ

```bash
./ask-llama.sh "Дай 10 вариантов заголовков для поста о Юваль Рафаэль"

# Через bridge-controller (рекомендуется)
./ask-llama.sh --preset YV_HEADLINES "Yuval Raphael rehearsal reaction"
```

## 🔗 ИНТЕГРАЦИЯ

- `bridge-controller` использует для пресетов **YV_HEADLINES**, **EY_REACTIONS**, **AL_LEGENDS**.
- `eleyia-writer` вызывает для генерации вариантов действий игрока (10+ штук).
- `yv-editor` использует для черновых заголовков перед финальным выбором.

## 📤 ОЖИДАЕМЫЙ ВЫВОД

Нумерованный список вариантов. Без воды, без преамбул. Скорость важнее глубины.
