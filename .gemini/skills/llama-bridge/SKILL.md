# 🦙 LLAMA BRIDGE V1.0

Этот навык позволяет Gemini CLI обращаться к локальной модели Llama 3.2 через Ollama.

## 🛠 КОГДА ИСПОЛЬЗОВАТЬ:
1. **БЫСТРЫЕ ПРОВЕРКИ:** Когда нужно проверить грамматику или стиль без задержек сети.
2. **ЛОКАЛЬНЫЙ КОНТЕНТ:** Генерация простых списков, вариантов названий или коротких текстов.
3. **ПРИВАТНОСТЬ:** Если данные не должны покидать локальную машину.

## 📋 ИНСТРУКЦИЯ ПО ВЫЗОВУ:
Для обращения к Llama используйте:
`./ask-llama.sh "Ваш запрос"`
