# 🛡️ CODE SENTINEL V1.0 (Технический Валидатор Хаба)

Этот навык защищает публичные и локальные версии интерактивного Хаба от критических ошибок кода и верстки, предотвращая "белый экран".

## 🛠 ОБЯЗАННОСТИ:
1. **СИНТАКСИС КОДА:** Проверять изменения в HTML, JS и JSON (data.js) перед любым коммитом в `YourEurovision_Hub_Deploy/` или корневой директории.
2. **ЗАПРЕТ ОДИНОЧНЫХ ПЕРЕНОСОВ:** В JavaScript-вызовах `replace` запрещены реальные переносы строк внутри регулярных выражений (только `\n`). Любая питоновская замена (через `re.sub`) должна использовать `\\n` для защиты экранирования.
3. **ЗАГОЛОВКИ MARKDOWN:** Жесткий контроль структуры постов `.md`. Запрещено начинать строки в теле поста с символов `#`, `##`, `###` (заголовок H1-H3 ломает регулярные выражения парсера новостей).
   - Правильный формат: `[Эмодзи] **#РУБРИКА: НАЗВАНИЕ**`.
4. **ВАЛИДНОСТЬ ССЫЛОК:** Все URL в тексте (особенно YouTube) должны быть корректно обернуты: `[Текст](https://...)`. Plain-text ссылки ломают логику встраивания плеера.

## ✅ ЧЕК-ЛИСТ ПЕРЕД КОММИТОМ КОДА ИЛИ ПОСТА:
- [ ] Проведен ли синтаксический тест `node -c data.js` (или `debug.js`) при изменении кода интерфейса?
- [ ] Содержит ли черновик поста запрещенные H1-H3 теги (`#`) в начале строки?
- [ ] Закрыты ли все HTML-теги (`<div>`, `<span>`, `<iframe>`) в свежих компонентах сетки?
