# 🛡️ Code Sentinel V2.0 (Технический Валидатор)

Этот навык защищает Hub (`YV_Editor_Hub.html`, `data.js`) и контент-файлы от синтаксических ошибок перед публикацией.

## 🛠 ОБЯЗАННОСТИ

1. **СИНТАКСИС КОДА:** Проверять HTML, JS и JSON перед каждым коммитом.
2. **АВТО-ИСПРАВЛЕНИЕ:** Если `node -c data.js` выдал ошибку — передать в `./ask-deepseek.sh "Fix this code error: [ОШИБКА]"`. Если DeepSeek не справился — эскалировать в `claude-bridge`.
3. **ПЕРЕНОСЫ В REGEX:** В JavaScript `replace` запрещены реальные переносы строк внутри регулярных выражений — только `\n`. В Python `re.sub` использовать `\\n`.
4. **ЗАГОЛОВКИ MARKDOWN:** Запрещено начинать строки тела поста с `#`, `##`, `###` (ломает парсер новостей). Правильный формат: `[Эмодзи] **#РУБРИКА: НАЗВАНИЕ**`.
5. **ССЫЛКИ:** Все URL оборачивать в `[Текст](https://...)`. Plain-text ссылки ломают встраивание плеера.
6. **ЗАКРЫТЫЕ ТЕГИ:** Каждый открытый `<div>`, `<span>`, `<iframe>` должен иметь закрывающий тег.
