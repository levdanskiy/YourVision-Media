# 📊 Music Data Scout V2.0 (Чарт-аналитик)

Этот навык собирает и интерпретирует чартовые данные для подкрепления редакционных решений в YourVision.

## 🛠 КОГДА ИСПОЛЬЗОВАТЬ

- Трекинг позиций ESC-артиста в iTunes/Spotify перед публикацией поста.
- Проверка коммерческого потенциала песни (чарты как аргумент в прогнозе).
- Сравнение чартовых позиций конкурентов внутри одного Semi-Final.
- Входные данные для рубрики `#ODDS` и блока `ПРОГНОЗ` в DNA-постах.
- Мониторинг движения после ключевых событий (пресс-конференция, репетиция, дебют).

## 🚫 КОГДА НЕ ИСПОЛЬЗОВАТЬ

- Анализ самого видео/выступления — это `video-analyst`.
- Написание поста на основе данных — это `yv-editor`.
- Мнение аудитории / соцсети — это `yv-global-scout`.
- Если данных нет (артист не в чартах) — указать "вне чарта", не придумывать.

## 📞 ВЫЗОВ

```bash
# Поиск по артисту или песне
./ask-charts.sh "Yuval Raphael"

# Поиск по конкретному треку
./ask-charts.sh "New Day Will Come"

# Сравнение нескольких артистов
./ask-charts.sh "Yuval Raphael vs Gabry Ponte vs JJ"
```

## 🔗 ИНТЕГРАЦИЯ

- `yv-editor` запрашивает данные перед финальной сборкой DNA-поста.
- `yv-chart-master` использует для еженедельных чарт-апдейтов.
- `yv-radio-director` сверяет с радиоданными для полной картины.
- `hub-engine` получает агрегированные данные для отображения в Hub.
