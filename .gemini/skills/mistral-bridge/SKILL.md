# 🌬️ Mistral Bridge V2.0 (Культуролог)

Этот мост делегирует задачи с культурным и историческим контекстом модели Mistral через `./ask-mistral.sh`.

## 🛠 КОГДА ИСПОЛЬЗОВАТЬ

- Историческая справка о стране на Евровидении (фольклор, культура, музыкальные традиции).
- Европейский контекст для постов YourVision (региональные нюансы голосования, политика).
- Творческий штурм для Almanac: мифологические параллели, культурные ассоциации, цитаты.
- Генерация вариантов названий, заголовков с европейским флёром.
- Eleyia: детализация мира (Amber Age, архитектурные детали, исторические реалии).

## 🚫 КОГДА НЕ ИСПОЛЬЗОВАТЬ

- Технические задачи (кодинг) — это `deepseek-bridge`.
- Финальная редактура поста — это `yv-editor`.
- Свежие новости (Mistral не знает сегодняшнего дня) — это `yv-global-scout`.

## 📞 ВЫЗОВ

```bash
./ask-mistral.sh 'Дай историческую справку о музыкальных традициях Сербии для ESC-контекста'
```

## 🔗 ИНТЕГРАЦИЯ

- `yv-editor` вызывает через `./ask-mistral.sh` когда нужен страновой контекст.
- `bridge-controller` использует пресет **AL_RESEARCH** для Almanac-задач.
- `almanac-heritage-curator` использует для параллелей мифов и культурных отсылок.

## 📤 ОЖИДАЕМЫЙ ВЫВОД

Структурированная справка: факт → контекст → применение. Без воды, без вводных фраз.
