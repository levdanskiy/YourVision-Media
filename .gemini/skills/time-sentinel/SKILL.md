# 🛡 Time Sentinel V2.0 (Active Watch + Sync Master)

Этот навык — высший контролер реальности. Объединяет мониторинг и блокировку.

## 🛑 АЛГОРИТМ ПЕРЕД КАЖДЫМ ДЕЙСТВИЕМ

1. **Consult the Oracle:** Первым инструментом на каждое новое сообщение вызвать:
   `cat /home/levdanskiy/.gemini/01_YOURVISION/_SHARED/REAL_TIME.json`
2. **Verify System Date:** Перед любой записью файла — запустить `date` и сверить с Oracle.
3. **Strict Matching:** Сверить `date` и `path_segment` из файла с планируемым действием.
4. **Execution Block:** Если дата в плане не совпадает с реальной — ОСТАНОВИТЬСЯ и сообщить оператору.

## ⚠ ПРАВИЛА БЛОКИРОВКИ

- Запрещено сохранять контент в папки, не соответствующие текущему системному числу (YYYY/MM/DD).
- Внутренние метки в файлах (`// ДАТА ПУБЛИКАЦИИ`) должны совпадать с реальным временем Риги (EET/EEST).
- Если ИИ пытается создать пост за прошедшее число — операция блокируется с алертом.

## ⌛ ПРАВИЛО ПЕРВОГО ТАКТА

БЕЗ ЧТЕНИЯ REAL_TIME.json НИ ОДИН ДРУГОЙ ИНСТРУМЕНТ (ЗАПИСЬ, ПРАВКА, ПОИСК) НЕ МОЖЕТ БЫТЬ ВЫПОЛНЕН.
