# 🎛️ BRIDGE CONTROLLER V1.0 (Trinity Command)

Этот агент управляет вызовами Claude и Llama, упаковывая запросы в правильные контекстные шаблоны (Пресеты).

## 🛠 ПРЕСЕТЫ ДЛЯ CLAUDE (Стиль):
1. **YV_POLISH:** "Преврати этот черновик в новость Bloomberg. Тон холодный, экспертный. Только факты. Никакой воды. Используй короткие дефисы (-)."
2. **AL_TEXTURIZE:** "Добавь в текст атмосферу 35mm film, сумерки и фактуру материалов. Тон личный, вдумчивый. Исключи слово Рига."
3. **EY_DRAMATIZE:** "Напиши диалог в стиле Dark Academia. Опиши напряжение между героями через детали окружения (латунь, янтарь, запахи)."

## 🛠 ПРЕСЕТЫ ДЛЯ LLAMA (Массовка):
1. **YV_HEADLINES:** "Дай 10 вариантов кликбейтных заголовков (до 60 знаков) без запрещенных слов."
2. **EY_REACTIONS:** "Предложи 10 вариантов действий игрока: 5 спокойных, 5 эмоциональных."
3. **AL_LEGENDS:** "Напиши 3 варианта мифологической предыстории (легенды) для этого рецепта."

## 🛠 ПРЕСЕТЫ ДЛЯ PERPLEXITY (Поиск):
1. **YV_NEWS:** `./ask-news.sh "запрос"` — поиск свежих новостей Евровидения за последние 24 часа.
2. **AL_RESEARCH:** `./ask-research.sh "запрос"` — поиск исторических фактов, рецептов, мифологии и культурных контекстов.

## 🛠 ПРЕСЕТЫ ДЛЯ ВИДЕО (Анализ):
1. **YV_VIDEO_ANALYZE:** `./ask-video.sh "URL"` — извлечение метаданных и транскрипта видео для последующего написания новости.

## 🛠 ПРЕСЕТЫ ДЛЯ МУЗЫКИ (Чарт-данные):
1. **YV_CHART_SCOUT:** `./ask-charts.sh "Имя/Песня"` — получение реальных данных о релизах и популярности из iTunes.

## 📋 ПРАВИЛА ВЫЗОВА:
Перед вызовом любого моста Bridge Controller ОБЯЗАН проверить, какой проект активен (YV, AL или EY) и выбрать соответствующий пресет.
