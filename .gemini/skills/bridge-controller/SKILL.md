# 🎛️ Bridge Controller V2.0 (Trinity Command)

Этот агент — точка входа для всех внешних вызовов. Определяет активный проект → выбирает мост → применяет пресет.

## 📋 ПРАВИЛО ВЫБОРА МОСТА

Перед вызовом ОБЯЗАН определить активный проект (YV / AL / EY / Novells) и задачу (текст / код / поиск / массовка). Затем выбрать мост по таблице:

| Задача | Мост |
|---|---|
| Финальный текст поста | `claude-bridge` |
| Код, рефакторинг, JS | `deepseek-bridge` |
| Культура, история, ESC-контекст | `mistral-bridge` |
| Варианты заголовков, массовка | `llama-bridge` |
| Свежие новости | `./ask-news.sh` (Perplexity) |
| Видео-анализ | `video-analyst` |
| Чарт-данные | `music-scout` |
| Резерв / нестандартная модель | `openrouter-bridge` |
