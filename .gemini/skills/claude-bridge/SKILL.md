# 🤖 CLAUDE BRIDGE V1.0

Этот навык позволяет Gemini CLI делегировать задачи агенту Claude Code через локальный CLI интерфейс.

## 🛠 КОГДА ИСПОЛЬЗОВАТЬ:
1. **СЛОЖНЫЙ РЕФАКТОРИНГ:** Когда нужно переписать большой объем кода с глубоким пониманием контекста Anthropic.
2. **ВТОРОЕ МНЕНИЕ:** Для проверки архитектурных решений или лора проекта.
3. **СПЕЦИФИЧЕСКИЕ ЗАДАЧИ:** Если Claude Code лучше справляется с определенным стеком технологий.

## 📋 ИНСТРУКЦИЯ ПО ВЫЗОВУ:
Для обращения к Claude используйте скрипт:
`./ask-claude.sh "Ваш запрос"`

## ⚠️ ОГРАНИЧЕНИЯ:
- Максимальное количество итераций (turns) ограничено до 3.
- Ответ возвращается в текстовом формате.
