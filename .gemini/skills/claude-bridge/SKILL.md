# 🤖 Claude Bridge V2.0 (Резервный Интеллект)

Этот мост передаёт задачи Claude Code через `./ask-claude.sh`. Используется когда задача требует глубокого рассуждения, а не просто генерации.

## 🛠 КОГДА ИСПОЛЬЗОВАТЬ

- Сложный рефакторинг с большим контекстом (больше 200 строк).
- Архитектурные решения: стоит ли вводить абстракцию, как разделить модули.
- Второе мнение по лору проекта или логике агентов.
- Отладка Python-агентов когда `deepseek-bridge` не справился.
- Ревью кода перед мержем в main.

## 🚫 КОГДА НЕ ИСПОЛЬЗОВАТЬ

- Написание постов — это `yv-editor`.
- Простые однострочные правки кода — вызывать напрямую.
- Культурный контекст для ESC — это `mistral-bridge`.
- Если задача укладывается в `deepseek-bridge` — предпочесть его (экономия токенов).

## 📞 ВЫЗОВ

```bash
./ask-claude.sh "Отрефактори этот модуль: [код]"

# С пресетом bridge-controller
./ask-claude.sh --preset YV_POLISH "Черновик поста: [текст]"
```

**Ограничение:** максимум 3 итерации (turns) за сессию.

## 🔗 ИНТЕГРАЦИЯ

- `bridge-controller` выбирает этот мост для пресетов **YV_POLISH**, **AL_TEXTURIZE**, **EY_DRAMATIZE**.
- `code-sentinel` передаёт сюда ошибки если DeepSeek не справился.
- `deepseek-bridge` — первый выбор для кода; этот мост — запасной.

## 📤 ОЖИДАЕМЫЙ ВЫВОД

Зависит от пресета. Код возвращается без объяснений; текст — в заданном тоне. Всегда проверять через `brand-integrity-officer` перед публикацией.
