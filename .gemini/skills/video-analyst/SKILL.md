# 📺 Video Analyst V2.0 (Разбор выступлений)

Этот навык скачивает и анализирует видеоматериалы для редакционных выводов YourVision.

## 🛠 КОГДА ИСПОЛЬЗОВАТЬ

- Разбор репетиционного клипа: постановка, свет, мизансцена, движение.
- Анализ официального клипа перед написанием DNA-поста.
- Сравнение репетиции 1 и репетиции 2 — что изменилось.
- Проверка технических деталей (живой вокал vs бэк, число танцоров, реквизит).
- Оценка сценической харизмы артиста для блока `VERDICT`.

## 🚫 КОГДА НЕ ИСПОЛЬЗОВАТЬ

- Чарты и стриминг — это `music-scout`.
- Написание поста по итогам анализа — это `yv-editor`.
- Технические проблемы с yt-dlp (обновление бинаря) — это `deepseek-bridge`.
- Если видео недоступно (гео-блок, приватное) — сообщить, не пытаться обойти.

## 📞 ВЫЗОВ

```bash
# Анализ репетиционного клипа по URL
./ask-video.sh "https://youtube.com/..."

# С конкретным фокусом
./ask-video.sh "https://youtube.com/..." "сравни с репетицией 1, что изменилось в постановке"

# Технический разбор
./ask-video.sh "https://youtube.com/..." "живой вокал или нет? количество танцоров?"
```

**Бинарь:** `01_YOURVISION/02_ENGINE/bin/yt-dlp`

## 🔗 ИНТЕГРАЦИЯ

- `yv-editor` вызывает перед написанием репетиционного поста.
- `yv-fact-checker` верифицирует технические утверждения из анализа.
- `bridge-controller` может передать видео в Gemini Vision напрямую при наличии нативной поддержки.

## 📤 ОЖИДАЕМЫЙ ВЫВОД

```
Видео: [название] — [артист] | Репетиция 1, Semi-1
Постановка: 2 танцора, минимальный реквизит, центральная позиция
Свет: холодный синий → тёплый переход на бридже
Вокал: живой, стабильный, микродрожь на финальной ноте
Изменения vs R1: убрали дымовую машину, поменяли финальную позицию
Вердикт: визуально сильнее R1, сценически конкурентоспособен
```

Всегда: факт → наблюдение → оценка. Без домыслов, только то, что видно в кадре.
