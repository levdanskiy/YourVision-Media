# 🔌 OpenRouter Bridge V2.0 (Универсальный Резерв)

Этот мост открывает доступ к любым внешним LLM через `./ask-openrouter.sh`. Резервный канал системы.

## 🛠 КОГДА ИСПОЛЬЗОВАТЬ

- `deepseek-bridge` или `mistral-bridge` недоступны (сбой Ollama, отсутствие сети).
- Нужна модель с конкретными характеристиками (большой контекст, специализация).
- Эксперимент с новой моделью перед добавлением выделенного моста.
- Массовая генерация (несколько запросов параллельно через разные модели).

## 🚫 КОГДА НЕ ИСПОЛЬЗОВАТЬ

- Если основной мост доступен — всегда предпочитать специализированный мост.
- Для задач с секретными данными (OpenRouter = внешний API).
- Для финальной публикации без проверки `brand-integrity-officer`.

## 📞 ВЫЗОВ

```bash
# Базовый вызов (модель по умолчанию)
./ask-openrouter.sh 'запрос'

# С указанием модели
./ask-openrouter.sh --model 'anthropic/claude-3-haiku' 'запрос'
```

## 🔗 ИНТЕГРАЦИЯ

- `bridge-controller` переключается на этот мост при недоступности других.
- Не имеет прямой интеграции с конкретными навыками — только как fallback.

## 📤 ОЖИДАЕМЫЙ ВЫВОД

Зависит от выбранной модели. Всегда проверять через `yv-fact-checker` перед использованием в контенте.
